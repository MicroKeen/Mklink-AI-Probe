# SuperWatch 日志回放

桌面/Web 仪表盘的 SuperWatch 页，以及 `superwatch --visualize` 独立页面，
均可点击波形工具栏中的 **加载日志**。无需连接下载器或目标板。

## 操作

在 SuperWatch 工具栏打开 **日志 → 开始记录**，选择后台电脑的保存目录。
桌面本机窗口直接弹出系统文件夹选择器；浏览器和远程窗口保留后台目录浏览。
可以先开启记录，再开始采集；尚未收到采样时显示 **等待数据**。
取消文件夹选择不会创建日志。
只有明确开始记录才创建文件；平时只保留有限的内存显示缓冲，不自动保存日志。
后台将收到的采样连续写入 JSONL，不受显示暂停、页面刷新或显示缓冲区长度影响。
同一个按钮在记录中变为 **停止记录**，点击后排空待写数据并关闭文件；停止采集、断开设备或关闭后台也会完成保存。
每段最多 100 万个数值或 32 MiB，通道变化时另起一段，可按文件编号回放。
磁盘失败或写入队列溢出会明确显示失败，不把不完整记录报告为成功。

停止记录只保存 JSONL，**不会自动转换**。点击日志区域的 **转换为 Excel**，
才会在后台以较低优先级将本次记录的所有分段生成一个 `.xlsx` 工作簿。
界面显示转换进度、完成或失败，完成提示的悬停信息包含输出路径。
工作簿的 `Info` 页记录开始日期、完整性和时间含义；`Data 001` 等页将采样相对时间
和各变量分列，冻结表头并提供筛选。超过 Excel 行数上限或新增变量列时继续到下一页，
中断单独标为 `DISCONTINUITY`，不会插值补样本。变量名按文本写入，不作为公式。
Excel 数值约有 15 位有效数字，**JSONL 仍用于无损回放**。已有同名工作簿不会被覆盖。
转换按行写入，不把完整记录加载进内存；转换期间仍使用 CPU 和磁盘资源。
当前按钮针对后台保留的最近一次记录，请在开始下一次记录前触发所需转换。
停止或转换失败不会改写 JSONL。

CLI 和 MCP 控制的是同一个后台记录器：

```sh
mklink runtime call superwatch_recording_start --arguments '{"directory":"D:/logs"}'
mklink runtime call superwatch_recording_status
mklink runtime call superwatch_recording_stop
```

MCP 使用 `superwatch(action="recording_start", arguments={"directory":"D:/logs"})`，
另有 `recording_status`、`recording_stop`、`recording_export`。
手动转换需传入 `recording_status` 返回的 `path`，防止旧窗口误转新记录：

```powershell
mklink runtime call superwatch_recording_export --probe <设备> --arguments '{"path":"D:/logs/superwatch-...-0001.jsonl"}'
```

MCP 使用 `superwatch(action="recording_export", arguments={"path":"..."})`。
轮询 `recording_status` 的 `export_state`、`export_path`、`export_parts`；转换状态独立于采集状态。
记录可以在开始 SuperWatch 采样前开启。
目录必须已存在；重名文件不会覆盖。仅断开 AI 会话不会结束后台的记录。

1. 点击 **日志 → 加载日志**，选择本地 CSV、TXT、LOG、JSONL 或 NDJSON 文件。
2. 导入后暂停实时显示，直接在原 SuperWatch 波形图中查看日志。原来的 **开始 / 暂停 / 停止** 控制日志播放；支持 0.25–16 倍速。停止将播放位置归零，播完后点击开始可重新播放。
3. 拖动时间轴可向前或向后跳转，跳转后保持暂停；点击播放继续。
4. 沿用原图的横轴/纵轴缩放、拖动、缩略图定位、光标测量和 PNG 保存。调整时间视图会暂停播放，暂停后可浏览整段日志。
5. 勾选左侧日志通道控制显示；左侧数值是播放位置之前最近一次记录值。日志数据不允许写回目标。
6. 点击 **返回实时**释放日志内存，并恢复最新实时采集状态与通道。原来的缓冲区 CSV 导出按钮已移除。

文件仅在浏览器本地解析，不上传。回放不会连接、复位、写入目标，也不会改变
实时采集状态；如果后台正在采样或记录，它会继续。回放中的采集按钮与 P 快捷键只控制本地播放。

## 支持的日志

- **CSV**：兼容 SuperWatch 的 CSV 导出。默认 `timestamp` 列单位为秒；
  也识别 `_t`、`timestamp_s`、`time`、`time(s)`、`timestamp_ms` 和 `timestamp_us`。
  支持逗号、分号或 Tab 分隔、UTF-8 BOM、CRLF 和带引号的列名。
- **TXT/LOG**：兼容仪表盘“原始日志 → 保存”的格式：
  `[2026-10-02 12:00:00.050] motor.speed=1200, enabled=1`。
- **JSONL/NDJSON**：每行一个独立页面原始数据对象，例如
  `{"_t":0.05,"timestamp_us":123456,"motor.speed":1200}`。
  `_t` 优先，单位为秒；没有 `_t` 时使用微秒单位的 `timestamp_us`。

显示时间从文件首个样本归零。每个通道保留原始采样时间，空 CSV 单元格表示
该通道没有样本，不补零；同一通道、同一时间的重复值以最后一次为准。
TXT 显示日期按连续的本地时钟解析，不额外进行时区或夏令时转换。
日志中混入的实时写入事件作为元数据统计，不计为采样点，也不改变采样时间轴。
写入标记目前仅在实时曲线中显示。

不含时间戳的 CSV、工程配置 JSON、时间戳倒退、非法/非有限数值、重复列名和
只有时间戳的空样本会被拒绝，并尽可能显示具体行号。多次采集重置时间戳后拼接
的文件应拆为各自的连续记录。CSV 不支持跨行字段。

## 大文件与边界

- 最大 256 MiB、64 通道、800 万个数值。
- 在后台线程分块读取并显示进度，可点击返回实时取消。关闭页面、切换仪表盘或重新导入
  都会终止旧解析任务并释放其数据。
- 绘图按像素保留最小/最大值，缩略查看仍保留尖峰；回放倍速改变的是时间推进速度。
- 回放只能使用实际保存的数据。CSV 导出和原始日志保存可能仅包含当时缓冲区内的
  数据，不能恢复已被覆盖的历史，也不代表自动进行了全程录制。
