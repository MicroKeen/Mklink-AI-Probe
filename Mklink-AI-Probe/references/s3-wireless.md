# ESP32-S3 无线桥接入共享后台

本入口适用于带 S3 适配组件的无线工作台。S3 经 USB OTG 连接 MKLink；
电脑通过 Wi-Fi、AP 热点或加密 BLE 访问 S3。目标调试继续使用现有 Device、
任务记录、采集缓存和 Site Agent 协议。

## 用户接入

1. 在无线工作台完成节点配对和网络配置，确认 V4 与目标板连接、供电正常。
2. 打开“共享目标调试”，选择节点、无线链路、目标工程和匹配目标固件的
   AXF/ELF；填写 USB 配对获得的节点管理密钥，点击“接入共享后台”。
3. “当前共享会话”显示实例、客户端和技能站点。“打开调试工作台”使用
   现有 MKLink GUI 的内存、烧录、RTT、SuperWatch 和 SystemView 页面。
4. AI 用已有远程 MCP 的 `remote_sites()` 找到工作台显示的站点，调用
   `remote_connect(site=...)`，后续继续使用 `remote_call`、`remote_flash`。
   不独立打开 USB 串口或建立第二个 S3 调试通道。

站点名为 `s3-<节点ID>`；AP、STA、BLE 共用这个身份。新版远程 MCP 刷新站点
清单；旧进程若看不到新站点，重启该远程 MCP 进程后再查。工具协议保持不变。
节点管理密钥与 Site Agent 访问令牌是不同凭据，前者不传给远程技能。

## 会话和能力边界

- 工作台、调试 GUI 和技能各有客户端会话，共用一个设备连接。退出本窗口
  不退出其他客户端；普通技能收尾用 detach。
- 先查采集状态。已有 RTT 使用无参数启动来订阅，各消费者保存自己的
  channel/cursor；不要为了读缓存停止别人的采集。
- 切换无线链路、凭据、网络配置，或安装/OTA 更新 S3 固件前，结束该节点
  全部调试会话，等待后台释放设备。
- 无线文件支持 SHA256 校验的 BIN/FLM，单文件上限 1 MiB。BIN 在加载 FLM
  前上传完成，烧录继续使用原有后台任务和校验。HEX 必须显式转换；本机
  CMSIS-DAP、MSC、UF2 入口不适用于无线节点。
- 结果未知时不重发、不自动重连、不回退本机 USB。查询原任务 ID 和节点
  状态，按明确恢复流程处理，不能把超时当成写入失败。

工作台默认启动有独立令牌的本机 `ws://127.0.0.1` Site Agent。跨主机部署沿用
[现有远程接入](commands-remote.md)；`wss://` 需要有效 TLS 终端，不能只改地址
前缀。本入口不自动开放公网监听或修改电脑网络。

开发环境安装 `s3` 及原有 GUI/MCP extras；配套工作台安装包自带后台组件。
官方发行版是否包含此适配器，以对应版本说明为准。

工作台仅为无线站点设置 60 秒操作预算和 1200 秒烧录预算，其他站点保持原值。
地址、令牌或预算变化后需要显式重连。烧录结果未知时先查询原任务或请求 ID，
不能重发；等待预算用于传输与完整校验，不代表自动重试。

## 配套程序的技能入口

无需替换已安装的 MKLink 技能或单独安装 Python。将 MCP 客户端的 command
设置为工作台资源目录 `device-tool/shared/mklink-sidecar.exe` 的绝对路径，
args 设置为 `["remote-mcp"]`。这是原有 `mklink.remote.mcp` 的打包启动入口，
工具名和协议不变。启动后先 `remote_sites()`，再连接工作台显示的站点。
也可用同一程序的 `remote --site <站点> status` / `capabilities` 命令。
注册信息沿用用户自己的 MKLink 站点目录，不把令牌填入 MCP 命令行。
