## 行为

- HPM JTAG 脚本用 `hpm.jtag_presence_supported()` 检查配套接口，使用静默的 `hpm.read_idcode()` 实时检测，替代会打印且仅返回缓存的 `cmd.get_idcode()`。
- 每板全部镜像/配置成功后，连续模式先确认两次有效连接再蜂鸣一次，随后以 100ms 间隔等待三个连续无响应读数，再等待下一次接入。最后一轮不再等待拔板；单次不做完成后的连接等待。
- `-4` 不稳定读数既不代表连接也不代表断开：清连续计数，在原等待超时内继续读取。忙、错误目标、取消和不支持返回仍终止；不重放写入或复位。
- HPM 仍采用原 ROM API 各文件的复位行为，本次未改成多文件原子事务，也不追加通用 SWD reset。实时 JTAG ID 仅代表链可访问，不证明应用启动，也不唯一标识板子。
- 自动次数默认 1；ARM/HPM 非 ISP 页面只有次数大于 1 才显示目标连接／换板等待时间，隐藏期间保留填写值。ISP 握手超时独立保留。版本信息加入简短说明。
