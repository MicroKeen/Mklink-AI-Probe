# MKLink AI Probe 0.4.1

本版本修复固件升级和脱机下载器识别，适用于 Windows 上位机与完整用户 Skill。

- 修复“检查固件”和“升级到最新固件”点击无响应；检查下载器固件无需先连接目标芯片。
- 固件操作绑定所选下载器，检查与升级进度、错误信息可持续查看。
- 下载最新固件时保留完整版本文件名。V2 使用 `.rbl`，V3/V4 使用 `.uf2`，文件名跟随实际固件版本更新。
- 脱机烧录自动识别已插入下载器的型号和固件版本，多台设备可明确选择；无法识别时保留手动选择。
- 修复页面切换、设备插拔及识别失败后残留的型号和部署预览状态。

公网远程中继留待后续版本，0.4.1 继续使用现有局域网/VPN 远程功能。本次上位机和 Skill 更新不发布新的下载器固件。
