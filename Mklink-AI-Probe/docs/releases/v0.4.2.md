# MKLink AI Probe 0.4.2

待构建、未发布。2026-10-30 按维护者要求准备下一次构建的版本号和更新说明。
当前已安装的 Windows 与完整 Skill 仍为 `836d8ea3` 的 0.4.1 本地测试包；
正式 0.4.1 资产保持不变。正式发布仍需明确指令。

- Windows 覆盖升级自动清理旧版 MKLink 元数据，修复安装后仍显示旧版本的问题。
- 在线烧录自动暂停相关采集，完成后恢复原任务；已完成的请求自动收尾，避免残留待确认提示。
- 修复 HPM 烧录复位后 RTT 自动恢复失败，保留自动发现的通道与原有编码设置；实际恢复错误仍记录在任务日志。
- 完善 HPM AI Skill 对暂停、单步、断点、核心寄存器及 ELF 变量调试的支持说明，并按固件能力开放操作。
- HPM 使用受支持的 JTAG 4/10/20/30 MHz 档位，避免将 SWD 频率设置当作 JTAG 时钟。
- SuperWatch 内置九个 HPM 系列的厂家 XML 外设目录，支持按系列匹配、手动导入 SVD/XML，以及外设寄存器只读观察。
- 内存读写首次访问自动建立二进制 MUX。配套固件支持一次请求读取最多 4 KiB；旧固件保持原有分块，写入与校验规则不变。
- 减少连续内存请求的重复设备枚举与本地通信开销，优化 Windows 串口接收响应。
- 配套固件优化 ARM SWD 连续 RAM 采样，减少 16/64 字节连续区域的读取开销；此项需要相应下载器固件。
- 修复连续内存采集停止确认及错误传递，启动回显和未完成的尾部样本分别统计，避免停止失败后误报可用。
- 修复 HPM SystemView U32 数据解析，改善 RTOS Trace 事件显示。

HPM CPU 调试、整块内存读取及部分采集恢复能力需要配套下载器固件，
上位机版本号不代表所有下载器型号都已具备这些能力。
配套固件的 16/64 字节优化已在普通 V4＋STM32H7、原 0.4.1 测试包上完成同条件复测：
30 MHz 下三轮吞吐中位数分别从约 151.5/152.7 kB/s 提升到 429.4/830.6 kB/s。
这是该硬件组合的固件实测，不能替代 0.4.2 安装验收，也不代表 HPM/JTAG 或所有目标的速度。
