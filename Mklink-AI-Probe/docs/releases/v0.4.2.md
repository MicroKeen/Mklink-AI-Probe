# MKLink AI Probe 0.4.2

- 完善 HPM 烧录与调试，修复烧录后 RTT 恢复及遗留请求提示；在线烧录成功后自动清理本次复制的临时镜像。
- SuperWatch 内置九个 HPM 系列外设目录，支持手动导入 SVD/XML，统一搜索变量、信号分组和图例的曲线显隐按钮。
- RTT、串口支持持续记录到本地并在原窗口回放；RTT 编码、显示和日志控制合并为一行。
- 连接配置分别保存 SWD/JTAG 时钟，默认 10 MHz，按下载器能力提供完整档位。
- 完善 Skill、MCP 和上位机的命令能力检查、HPM 核心调试及采集恢复，改善 RTT/RTOS Trace 并行采集和 STM32H7 硬件断点；相关能力需配套固件。
- 优化内存读写、设备识别和连接失败提示；HPMLink 连接后自动显示对应品牌。
- 修复 Windows 覆盖升级后仍显示旧版本的问题。

下载包含 Windows 安装包、完整 AI Skill 和 Site Agent。安装包与 Skill 使用同一版本源码；下载器固件独立更新，不包含在安装包中。公网远程中继继续延期。
