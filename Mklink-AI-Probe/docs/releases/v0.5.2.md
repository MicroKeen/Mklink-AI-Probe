# MKLink AI Probe V0.5.2 客户验证版

- 配套 V3.7.1、V4.7.5 固件可直接读取 S32K3 的硬件型号。无需先加载 ELF，桌面、Web、CLI 和 MCP 共用同一 AP4 连接，支持 RTT、SuperWatch 和内存访问。
- 在第二个桌面或 Web 窗口连接同一探针，可查看当前采集。任一窗口明确断开时，后台停止目标、串口与 Modbus 采集并释放端口。
- S32K3 的“重启 MCU”使用型号配置中的功能复位。目标掉电时显示“目标待确认”，再次开始采集会核对原硬件型号和 MEM-AP。
- 可以在原连接上更换 ELF、AXF 或 IAR OUT。符号文件标注的芯片与实物不一致时，Web 和桌面的“文件来源”会同时显示两个型号。
- 在线烧录独立校验目标、主核及 Flash 算法。目录支持识别 22 个 S32K3 型号，其中 6 个提供内置 Code/Data FLM，其余可导入匹配的厂商算法。

本轮完成全部 22 个型号的主机与固件模型联测，以及普通 V4 和 V3 连接 STM32F103 的实板回归。S32K3 新识别流程的实板冷启动待客户验证。型号清单、固件能力与历史实测见[验收记录](../verification/v052-s32k3-family.md)。
