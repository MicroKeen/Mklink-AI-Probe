# MKLink AI Probe V0.5.0

Windows 上位机、完整 Skill 与 Windows Site Agent 更新。

- 修复普通用户连接和覆盖安装权限；Windows 默认按用户安装，不再自动修改端口名称。
- 改善 SuperWatch 断线恢复与采集中写入，变量和采集配置随 AXF/ELF 自动保存、恢复。
- 日志改为手动转换：SuperWatch 导出 Excel，RTT 导出精简的带时间戳 TXT。
- 修复 RTOS Trace 再次启动时的任务名称刷新，优化 Timeline 连续显示、缩放和平移；修复多窗口事件更新时误报后端离线。
- Skill/MCP 可操作桌面和 Web GUI 的页面、控件、文件及 SystemView、RTT、SuperWatch、串口日志回放；回放不停止其他窗口的采集。
- 修复多下载器独立连接、单窗口切换与 USB 拔插后的选择保持；恢复等待缩短至 0.5 秒。显式重启 MKLink 可停止当前采集后执行。
- HPM 在线/脱机烧录按芯片选择配置，支持用户填写外部 NOR Flash 参数；优化脱机 OTP 配置界面。
- 补全串口和 Modbus 波特率档位至 10M，修复部分 ELF 变量遗漏，支持通用工程初始化和显式重载符号。
- 修复 macOS 后台启动和 USB 身份识别，优化枚举耗时与共享会话续约。
- 新增客户端和固件更新提醒，协调更新顺序；默认从腾讯云下载，不可用时回退 MicroKeen GitHub。

配套发布 MicroLink V2.9.4、V3.7.0、MicroLink V4.7.4 和 HPMLink V4.7.4。两款 V4 均支持 Arm SWD 与 HPM JTAG，升级时必须选择对应下载器型号的文件。建议先更新上位机/Skill、重载 MCP，再按提示升级固件。

Windows 覆盖安装会结束当前用户的旧 MKLink、Skill/MCP 后台及正在执行的任务，请先保存数据。升级能力仍以固件协商为准。1 µs 极限三路采集和 10 Mbps / 16 KiB RS485 仍存在已知丢弃边界；STOP 低功耗访问取决于目标状态。本次不提供新的 macOS 安装包，Mac 原生窗口、Gatekeeper 和客户实物验收仍待完成。
