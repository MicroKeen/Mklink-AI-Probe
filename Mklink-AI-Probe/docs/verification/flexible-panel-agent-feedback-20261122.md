# 灵活面板的 Agent 图表更新与操作拒绝反馈

2026-11-22，以 `664495f1` 为基线，在 Windows 上使用本分支的默认生产 Web 资源、独立工程和真实 Chromium 检查了 `agent-ui-dev` 0.5.0 评审中的两处反馈。工程有一张图表卡和一张操作日志卡，展示数据来自基线的测试记录。

| 场景 | 实际结果 |
|---|---|
| Agent 更新图表 | 通过所选窗口公布的 `content.set` 写入三组数据。按原命令 ID 查询到 `completed`，读回三组标签和数值。仅目标卡出现紫色外框，提示和日志显示“Agent 已更新「验证结果」的图表”。高亮结束后，日志保留。 |
| 用户手动编辑 | 从图表的编辑表单修改内容，页面及语义状态同步；只产生用户操作记录。 |
| Agent 请求退出专注，布局版本已变化 | 手动进入专注后，向原页面发送带旧 revision 的退出命令。调用方收到原有的 HTTP 409 和 `STALE_REVISION`。当前窗口显示“已拒绝退出专注”及原因，回读仍处于同一张图表的专注视图。手动返回布局后，可在日志中看到拒绝记录。 |
| 第二窗口、窄屏和减少动态 | 打开同一后台的另一窗口，再次触发拒绝，第二窗口没有收到提示或日志。在 375 px 深色窗口实际执行图表更新和旧版本请求，提示在视口内。减少动态时，卡片使用静态轮廓，提示文字为浅紫色。 |

## 回归范围

后端保留现有调用方的拒绝响应，使用面向目标页面的有界提示队列。该窗口确认收到提示后清除相应记录。回归覆盖重试、响应丢失、页面重新登记、其他目标、通知数量上限，以及异步操作的终态与提示去重。页面端在原回执生成后呈现反馈，手动控件继续使用原业务逻辑。

完整 GUI 测试通过 139 个文件、1,452 项。面板、静态资源及公共契约相关 Python 测试通过 780 项，有两条依赖或路由警告。在与 CI 一致的 Python 3.12 环境单独复跑反馈契约，84 项通过。TypeScript 检查及 Vite 生产构建通过。

本轮使用未绑定设备的后台。原计划中的最终整仓 Python 和 Windows 原生桌面覆盖安装仍待合并验收。过往真机条件及整仓限制见[帮助与送审复核](flexible-panel-help-review-20261122.md)。
