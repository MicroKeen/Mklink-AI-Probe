# 灵活面板的 Agent 图表更新与操作拒绝反馈

2026-11-22，在 Windows 上按 `agent-ui-dev` 0.5.0 复核 `29cb268f` 之后的反馈样式。使用分支内的生产 Web 资源、独立测试工程和 Chromium，分别录制了深色与浅色主题。图表中的数值取自以前的本地测试记录，运行时未绑定设备。

| 场景 | 实际结果 |
|---|---|
| Agent 更新已有图表 | 通过目标窗口公布的 `content.set` 向两组柱形数据中补入第三组，并按原命令 ID 查到 `completed`，读回三组数据。仅图表标题栏以主题的信息色轻亮约 1.5 秒，显示“Agent 已更新”。两张卡片的标题栏和图表内容区位置保持稳定，键盘焦点仍在原控件上。日志保留完整记录。 |
| 用户手动编辑 | 通过原有表单填入图表数据，页面与语义状态同步，日志显示用户操作。 |
| 拒绝退出专注 | 进入图表专注视图后，使用过期布局版本调用退出命令。调用方收到 HTTP 409 和 `STALE_REVISION`。图表标题正下方出现“已拒绝退出专注　布局已变化，仍在专注查看。”，约 8 秒后提示消失。回读确认图表仍在专注。手动返回布局后，日志保留拒绝记录。 |
| 主题与减少动态 | 标题栏使用工作台原有的 `--info` 与 `--info-bg`，拒绝提示使用 `--warn` 与 `--warn-bg`。核对了深色、浅色及跟随系统时的浏览器计算样式。在 375 px 深色窗口开启“减少动态”，显示静态底色和“已更新”，示例卡名完整可见。 |
| 其他卡片与窗口 | 查看另一张卡时，后台图表更新不切换视图，点击“定位到图表”后才切换。同一后台的第二个窗口没有收到首个窗口的拒绝提示或日志。 |
