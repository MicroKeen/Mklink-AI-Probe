# 0.3.6 桌面启动优化与诊断入口调整

源码：`60bcc8df644103086211365193a8bf6b801e6b39`。本地 Windows preview 候选，未正式发布。

## 修改与原因

- “导出诊断包”从全局页脚移至“配置 → 后台管理”的顶部操作区。没有设备、后台状态读取失败或后台已退出时仍保留入口；远程访客继续不提供本机日志导出。
- 原 Windows 安装包使用 PyInstaller onefile。桌面代理与独立共享后台各自解压完整 Python、FLM 和 Pack 载荷，且后台必须独立于启动者存活，不能复用启动者的临时解压目录。
- Windows 改为 onedir，由 NSIS 一次性安装完整 `_internal` 依赖，两个进程直接读取安装目录。保留完整离线资源、原有窗口/后台所有权、超时预算和安装文件占用保护。没有以复用临时目录、延迟校验或移除算法换取速度。
- Tauri 当前资源路径归一化会丢弃 Windows 盘符，首次跨盘绝对路径打包失败。改为仅打包期间创建独有相对资源目录并在退出时清理，编译/缓存仍在统一 F 盘构建空间；再次构建成功。

## 实测

同一电脑、Windows-only PATH、每次创建独立无设备后台，从启动桌面代理到 `/api/health` 成功：

| 安装结构 | 第一次 | 第二次 | 第三次 | 中位数 |
| --- | ---: | ---: | ---: | ---: |
| 旧版已安装 onefile | 9.688 s | 9.765 s | 15.850 s | 9.765 s |
| 新包解压后 onedir | 1.629 s | 1.553 s | 1.530 s | 1.553 s |

新包在上述同机测试中缩短约 84%。这是后台就绪时间，不是所有客户电脑的完整窗口显示时间；未通过重启 Windows 清除文件缓存。
