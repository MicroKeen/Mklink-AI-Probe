## 脱机实写和独立读回

操作前读出目标全部 524,288 字节。所选 HEX 的应用地址范围为 `[0x08005000, 0x08021E00)`，共 118,272 字节。原程序与 HEX 的应用字节相同。使用脱机页部署并实际触发一次后，新连接独立读取全片，将读回与“原片内容加所选镜像”逐字节比较，差异为零。应用范围以外 406,016 字节也相同。全片 SHA-256 为 `9ee6f70683294746763907c1c730f80cebe06b5c1783c455c1de0838766a2e56`。验证后已恢复探针盘原有文件和原桌面后台连接。

相关 Python 回归 797 项通过。另跑脱机烧录、MUX、RTT 和 SystemView 相关 288 项，全部通过，两组有重叠。前端完整 141 个测试文件、1,491 项通过，TypeScript 和生产构建通过。

本轮实物证据为 Windows 源码后台、真实 Edge 和 stdio MCP。组件回归覆盖桌面共用视图和灵活面板。此次未制作新的 Windows 安装包。

## 跨系列应用

RTT 读者归属、SystemView 实际描述符探测、记录目录、忙提示和仪表盘布局由共享后台及组件实现。脱机 BIN 根据当前型号可用 FLM 的默认编程区域预填基地址，支持地址零。多片区没有唯一默认值时可显式选算法或输入地址。HEX 依据全部地址段，HPM 延用 ROM 路径。

ELF 识别使用内置 FLM 与 Pack 目录中的器件拼写，并保留原始证据。目录内的小写 x 表示封装或容量占位符，厂商名称中的字母 X 保持字面意义。具体料号冲突仍会显示。跨系列软件用例涵盖 STM32G0、GD32、AT32、N32、PY32、XMC、nRF 的头文件以及 S32K、nRF、XMC 的 BIN 基地址。
