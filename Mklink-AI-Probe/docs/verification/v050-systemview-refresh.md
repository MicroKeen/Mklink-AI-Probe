# V0.5.0 SystemView 刷新优化

日期：2026-11-14。显示优化提交 `a5cdf425`，历史与健康检查优化提交 `7b2da4f3`。最终假离线修复与GUI控制见 [后续验收](v050-gui-control.md)。
本轮沿用前轮目标 IRQ 锁和 CH2 8 KiB 缓冲，不改变下载器或目标固件。
前置证据与极限负载边界见 [SystemView 丢数据和重启报告](v050-systemview-loss-reboot.md)。

## 问题与修改

用户约 7.6 秒录屏显示事件继续更新时标尺存在停顿、随后追赶。代码原来将每批数据的
跟随动画固定在 100 ms 内完成；批次间隔波动时会提前走完并等待下一批。录屏帧率不等于
应用帧率，也不能由画面停顿推断目标丢包。

- 跟随采用独立显示时钟，保留约 180 ms 的缓冲余量吸收交付抖动，短窗口余量不超过
  窗口的 40%。显示右端不超过已收到的数据；断流后会停止，不伪造事件或修改原始时间。
- 画布仍使用自适应 60/30/20 FPS，取图请求最多 20 Hz，合并等待中的刷新；缩放、调整
  大小立即请求。运行统计和事件表只以 5 Hz 更新，采集和原始流不降频。
- 环形历史通过二分跳过像素桶内的中间区间，保持原先每像素首尾选择、精确 tick 和边界
  结果。时长统计按上下文维护频次，随历史淘汰同步删除；查询不再反复扫描并排序全部历史。
- 去除同批数据的重复布局、逐区间重复更新响应式上下文以及无变化图例的 DOM 重建。
- 暂停后缩放再继续时，取消旧查询并恢复最新数据跟随；断开重连后的新 Canvas 在 DOM
  安装后重新绑定，避免仍向已脱离页面的画布绘图。
- 显示时钟保留在独立的 `svTimeline.js` 内，离线 HTML 报告无需新增模块依赖。
  GUI、Skill Web 和 MCP 启动的 Web 共用同一生产资源，后台协议与原始记录格式不变。

## 双窗口健康提示修复

在首个安装候选中复现“后端离线但事件仍更新”。本节记录第一阶段优化；`7b2da4f3` 安装版仍复现假离线，随后已定位浏览器HTTP连接池被状态SSE占满并修复，见 [最终验收](v050-gui-control.md)。

- 后台 `_trim_history` 原来每个事件批次都筛选、复制全部保留历史（上限 100000 条），
  超出条数后再切片。线程采样命中该热点。现在以到达顺序索引和时间最小堆增量淘汰，
  同时保留无时间元数据、乱序时间戳、条数限制、游标缺口和晚到 CPU 频率补时语义。
  原始日志仍在有界显示缓存之前写入；没有减少采集或记录事件。
- 健康检查原先每秒启动一次，而单次超时为 3 秒，启动、手动检查可能重叠。
  现同一窗口共享在途检查，并通过代次和端点校验丢弃停止、重启或切换后的旧结果。
  真实失败、401 和启动超时仍报错，未延长 3 秒超时或以事件更新掩盖健康失败。
- 后端相关 232 项通过；GUI 全量 111 文件 / 1282 项通过，最终类型检查和生产构建通过。
  后端包含随机乱序/元数据与旧算法逐项比较、晚到时间补全、非有限值、计数淘汰和堆
  内存界限；100000 条历史追加 100 条事件只读取 100 次新增时间字段。
  前端覆盖慢检查去重、旧失败晚到、端点变化和真实授权/连接失败。

源码生产界面双窗口、同一 V4.7.4 / STM32F103RC，SWD 10 MHz、四变量 1 ms、
RTT CH0/1 与 Trace CH2。初次 30 MHz 连接出现异常 ID/RTT 控制块读取失败，
那轮未计作有效采集；显式断开后按 10 MHz 重连，确认三路实际运行后才取证。

- 两窗口事件和九个任务持续更新，一个窗口暂停/放大不影响另一个窗口。
  最终快照 11443874 事件，解析丢弃、目标溢出、MUX 和主机队列丢弃均为 0；
  SuperWatch 754479 组，读错/解析错误为 0。RTT 已开启但无文本载荷。
- 有效采集和两窗口下，120 次代理健康查询全部成功，中位 7.748 ms、最大 256.906 ms。
  较早旧实现双窗口 30 次查询中位 1.323 s、最大 1.995 s；前后连接时钟不同，
  不据此宣称严格同条件加速倍数。未开启采集的快速测量不作为本结果依据。
- 源码浏览器在更新后持续保持后端正常；实际关闭代理后两窗口都提示离线，
  重新启动代理后恢复正常，不自动连接或重放采集。测试采集、连接和窗口均正常释放。
- 首个 `a5cdf425` 安装候选曾有 15 个主机批次 / 6113 条事件的扇出丢弃，
  该候选不作为最终零丢弃证据；后续安装验收以 [最终GUI控制报告](v050-gui-control.md) 为准。
