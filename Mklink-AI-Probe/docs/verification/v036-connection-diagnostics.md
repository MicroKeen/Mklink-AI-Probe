# 0.3.6 连接诊断与客户导出验收

本次在现有 0.3.6 腾讯云预览任务分支继续完善主机日志。没有修改下载器固件、
恢复期限、目标供电或固件下载逻辑，也没有更新线上安装包、索引或正式标签。

## 行为

- runtime.log 每行加入带时区的毫秒时间戳和 PID，兼容 Python 分段输出及
  原生 stdout/stderr，继续保持有界轮换。
- 单独保存连接诊断 JSONL：首次串口/MUX 错误、异常链与系统错误码、
  MUX 请求及心跳超时信息、打开/关闭、主动生命周期、恢复及超时放弃。
- GUI 状态接口失败/恢复单独记录，不将其标为物理 USB 拔除。
- 底部“导出诊断包”支持本机保存 ZIP。无须连接硬件；桌面代理在共享
  后台不可达时也能导出已有记录。远程客人不开放本机诊断导出。
- 导出只收集专用连接记录与版本/OS清单，匿名化包内文件名，过滤凭证；
  不包含普通控制台、RTT/串口采集原文、工程、固件或 endpoint.json。
- 新增诊断文件无法创建/写入时不改变原通信行为。导出失败或取消不报成功。

用户使用及证据解释边界见 [connection-diagnostics.md](connection-diagnostics.md)。
日志有助于定位最初失败环节，不等价于已经定位本次 V3 间歇性断开的根因。
历史 Windows 记录混有用户恢复时的手动拔插，不能由此证明固件自动重启。
