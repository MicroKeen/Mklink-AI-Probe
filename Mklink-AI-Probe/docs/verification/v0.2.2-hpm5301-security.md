# HPM5301 OTP 安全功能实测报告（阶段记录）

日期：2026-09-18～19。硬件：V4 HPMLink、HPM5301 测试板；UART0 独立连接，115200 8N1。
本报告不是全部安全功能验收通过声明。签名启动正例及 SECURE → RETURN 已验证；撤销、签名失败反例、NONRET、加密功能仍待验证。

## 已完成的实测

| 测试 | 操作及观测 | 判定与边界 |
| --- | --- | --- |
| 用户区读写 | Word 79 从 0 写为 0x80000001，再写为 0x80000003；GUI 回读一致 | 通过，熔丝地址与高位整数正确 |

当前芯片不能通过 JTAG 再下载程序，需保留作保护保持性复测；后续开发使用空白芯片。

## 发现及修复

### 受保护内存被错误报告为全零

DEBUG_DISABLE 生效后，探针仍可读到 IDCODE，但旧 SBA 路径在 DMI 返回全零时
把 SBCS 当成“无错误”，继而向主机返回四个零字节。UART 同时回报真实的
安全字为 0x100A0001，因此这是无效读，不是数据本身为零。

固件修复：普通 SBA 读写（包括流读取的回退路径）开始前检查 SBCS 的版本、
地址宽度与 32 位访问能力。不可用时直接失败，不再产生虚构的内存内容。
已编译、升级 HPMLink.uf2，并在 DEBUG 已禁用的芯片上复测。

上位机修复：`Device.read_memory` 要求返回字节数等于请求长度；空响应和部分
响应均抛出明确异常，不再向 API 使用者返回空数据作为成功。
修复后的真机结果为：`returned 0 bytes, expected 4; target debug access may be disabled or unavailable`。
正常未锁目标的固件读写回归已在第二颗芯片完成：38,132 字节 ROM 下载、完整校验及递增 tick 通过。此前 52 项相关 Python 测试通过。

### 通用 halt/run 不作为本次 HPM 调试判据

审查发现主机通用 halt/run 路径采用 Cortex-M 寄存器模型，探针通用 CPU 命令在
本次 HPM 未锁状态也返回 -1。本报告没有把这些返回值当作 DEBUG_DISABLE 的证据。
禁用前的正常下载和内存读、禁用后的 SBA 拒绝、UART 独立读回及持续运行分别记录。
HPM 通用 CPU 控制接口的一致性另需修复验证。

## 测试程序及证据

第一版专用 hello_world 程序只接受有名操作 SWVER1、TCU、DEBUG、JTAG，要求精确
预期旧值、硅片标识和未锁状态；拒绝重复置位、未知命令及错误旧值。
上电不会自动烧写，不包含任意地址或任意掩码烧写入口。第二版增加限定实验根哈希和 SECURE/RETURN 两个精确状态转换。
串口只用于本次授权的可弃芯片实验，不是量产后门或正式 GUI 安全写接口。

串口发送采用逐字节节流；初次长命令被解析拒绝，未进入 ROM，随后使用显式
固定长度解析和节流输入。完整原始命令及结果保存在本地忽略目录的 UART 日志。

版本 1 测试 BIN：37,592 字节；SHA-256：
`e6dce1cf3c3ad307a4c3bcba42ed2c19ffcc6162f1fc1e798f7e8d4e08ae2e89`。
烧录地址 0x80000400，HPM ROM 后端完整校验通过。启动头复制在测试工程内，
未修改 SDK 公共启动头；以后编译此工程仍产生满足 OTP 版本 1 的镜像。

## 第二颗芯片：签名启动、生命周期与 GUI（2026-09-19）

初始安全字 0x10000001，HARD_LOCK 0x30400016，SW_VER 0，用户区空白。
Chrome 先完成 Word 69 的 0 → 1 写入、复位及回读。实验根证书由官方
HPM Manufacturing Tool 0.6.0 生成，使用四根 ECDSA P-256，签名索引 0。
证书、私钥、原始串口日志只保留在本地实验目录，不进入发布包。

| 阶段 | 实际结果 |
| --- | --- |
| 未烧根哈希，下载签名镜像 | Flash 字节校验成功，但 UART 无应用输出、tick 不增长；未进入 SECURE |
| 恢复实验程序，烧写 Word 80–87 | ROM 返回 0，8 个 word 与官方工具生成的哈希逐字一致 |

修复两处上位机问题：配置读取无论是否缓存 MCU 名称，都先检查实时 CHIP_ID，
避免把 SECURE 的固定返回值当成有效 OTP；连接变化立即清除旧配置、确认和写入计划。
状态轮询内容未变时不取消当前读取、不清空计划。Chrome 已观察到保护错误提示和空值，
RETURN 后再次读取显示 A/B=7；断开连接后旧 OTP 行消失。

RETURN 不能回退为 SECURE。NONRET 分支须使用新芯片，不能直接在该芯片置位冒充 NONRET 测试。
