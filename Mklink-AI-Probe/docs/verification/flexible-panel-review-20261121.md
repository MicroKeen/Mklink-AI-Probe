## 使用者窗口的关闭、缩放和变量滚动复测

实际工程原有 15 张卡片。复现时，在 1440 px 和 390 px 的普通模式下，可见关闭按钮和外部缩放手柄均为零。在 390 px 宽、480 px 高的变量卡上，信号分组显示高度为 88 px，可拖动上限仅 89 px。旧版窄窗固定卡片高度，同时按当前视口预算分配三个变量区域。

修复后，普通模式常显关闭按钮，宽屏可直接用 GridStack 边缘缩放。窄屏按卡片实际行数显示高度，底部分隔条支持指针和键盘，并复用面板几何与碰撞处理。独立变量面板允许分区超过当前可视高度并滚动到后续分区。外层卡片高度按 1–200 行校验，仍须满足类型的最小行数和布局空间约束。内部控制组件沿用原几何约束。

在同一工程及 AXF 下，用临时卡片进行真实浏览器操作，普通模式的宽屏高度从 352 增至 440 px，390 px 窗口从 440 增至 528 px，再按方向键缩小一行。变量分隔条从 180 增至 295 px；已选变量最后一行通过命中测试，滚轮能到达变量目录底部。关闭临时卡后保留全部 15 张原卡片。320 / 390 / 768 / 1440 px 的既有布局回归亦通过。

浏览器回归可用 `playwright-cli run-code --filename=_maintainer/testing/flexible_panel_resize.playwright.js` 在一次性窗口执行。前提是灵活面板已打开，并至少选中两个工程符号。测试不写入工程布局。

用户可见的官方 GUI 已加载原 AXF 的 1,914 个符号，选中原始 PPG、处理波形、质量、心率估值和两个有效标记共 6 项。显示窗口的变量分组设为 320 px，6 行同时可见。此次检查采用符号目录，无硬件采集。

本次修复的最终资源通过生产构建（含 TypeScript）、完整 GUI 单测 138 个文件／1,443 项，以及 frontend_storage、frontend_concurrency、runtime_frontend 后端回归 183 项（1 条依赖警告）。另在隔离工程中启动新后台，通过正式 API 保存、读回 18 行变量卡，revision 从 0 更新为 1。
