## 后续修复必须保留

1. 采样值、变量宽度/符号/偏移、时间戳及已发布样本计数正确；原始记录与回放一致。
   已确认缺失才置灰，未知连续性只断线，不能仅按时间间隔判丢失或插值伪造采样。
2. SuperWatch、RTT、调试及共存能力与性能不退化；普通读取同时检查 P95、长尾和
   间隔读取，不能只比较连续读取中位数。保留所有失败和完整性计数。
3. 物理所有权、身份/epoch、取消及错误边界、未知结果不重放等约束保持。
   不用缓存快照冒充实时读取，不修改用户目标固件来迁就采集。
4. 安装升级、配置保留、冻结运行、Web/原生显示和正常退出等已通过能力保持。

按改动影响范围执行既有检查：文案只需组件、生产 Web 和真实浏览器核验；
采集/传输/调试路径变动须用同一下载器、目标映像、时钟、翻转周期和负载进行
修复前后实测，必要时反测，核对原始值和时间戳。不得拿不同环境的吞吐数直接判优。
性能差异须结合重复波动、P95、最大值、完整性和共存结果；出现可重复退化不得作为
修复交付，尚不能区分退化与波动时明确记录待验，不宣称“无退化”。

参考环境中，原 USB7 的 4 B 持续采样约 26.44 万次/秒，独立 RTT 约 853.5 KiB/s；
PE2/RAM 的普通批间中位数约 22/21 µs。这些是带条件的观测值，不是所有硬件的固定门限。
最大采样间隔 20 µs、40 µs 零漏采、普通读 P95/间隔读取稳定小于 1 ms 仍未达到。
