实读 V4.7.0、STM32F103RE 512 KiB。用户确认 UART5 接线。原工程分阶段测试，
不备份/还原测试代码；最终保留 UART/RTT CH0/1、SystemView CH2 和 PID 测试固件。
全编译有四项既有 RT-Thread libc nonnull 警告，末次增量编译 0 错误/0 警告。
未修改供电设定、探针固件或 OTP。电压/电流仅验证读取，不等同精度校准。

定点修复恢复 Keil/pyOCD 枚举；未更换驱动包，枚举异常的历史根因仍未闭环。

- 内置 FLM 在线下载：56 个应用扇区编程/校验/复位成功，引导区前后哈希一致；
  113920 字节应用回读与当时 AXF 完全一致。

## 保留限制与后续

30 MHz 并行读取偶发错误继续保留交接，低速通过不代表任意负载无损。
本轮不能替代 RS485 电气层、HPM 多板完整下载、N32 外置 Flash、其他探针/MCU、
跨物理主机 Agent 或其他系统实体 USB 认证；相关历史未解事项不因合并而关闭。
正式发布仍需从已整合的源码确定发布提交、签名和渠道操作；当前文件是本地候选。

详细日志、原始失败、波形、固件及设备标识保留在构建根本轮 reports/artifacts，
不提交到 Git。最终合并状态以 GitHub PR 与 main 精确祖先核对为准。
