# 0.4.2 收发日志与曲线显隐

RTT 各通道与串口助手的收发窗口使用“日志”菜单选择目录、开始/停止持续记录、加载日志回放。
桌面本地连接使用原生目录选择器；浏览器及远程连接选择后台电脑的目录。
记录由后台直接消费原始 RX/TX 字节，不依赖显示缓存、编码、页面订阅或暂停显示。
停止采集会排空记录队列并关闭文件。原有串口 TXT/CSV API 保持兼容。

日志包含来源、方向、采集会话、时间、原始十六进制字节和接收丢失计数。
自动分段限制为约 4 MiB 或 20,000 条记录；文件名唯一，排他创建，不覆盖旧文件。
写盘队列有界，磁盘错误或队列溢出明确标记不完整，不阻塞设备采集。
回放接受单个至多 16 MiB 的 JSONL 分段，提供播放/暂停、速度、定位与通道选择；
在原收发、终端及 RTT HEX 窗口显示，隔离实时流并禁用该窗口的设备发送。
不完整、未正常收尾或带丢失记录的日志显示警告；不会重新执行日志里的 TX。

SuperWatch 信号分组和曲线内图例都显示眼睛按钮，与变量树共用显隐状态。
隐藏曲线保留采集、分组和变量选择；图例保留隐藏变量，允许原地恢复显示。
回放显隐与实时显隐分开保存。

新增 HTTP 接口为 `/api/dash/{rtt|serial}/traffic-recording/{status|start|stop}`。
`start` 使用 `directory` 和可选 RTT `channel`（0–7）；`status`、`stop` 使用通道查询参数。
串口记录包括当前后台打开的所有串口，回放选择日志中的来源。

验证范围包括：分段及排空、字节和方向完整性、磁盘失败隔离、多通道/多串口、
回放时序和定位、编码跨块、会话隔离、实时/回放隔离、显隐双向同步，
以及全量 Python/GUI 回归。实际安装、设备与界面验收结果记录在当前交接，
本说明不代表已完成正式发布资格认定。
