本轮四份指定交付包为 MicroLink V2.9.1、V3.6.6、V4.7.0 和 HPMLink V4.7.0。只更新主机端识别和分发，不操作实体下载器。

## 修订识别

- 随包目录保存四份交付的版本、构建时间、文件大小、SHA-256 和三个下载源，不打包固件二进制。
- 版本相同时比较下载器 readme 的编译时间。旧构建可升级；未知构建允许明确确认后重新安装；较新版本或构建拒绝降级。
- 写入前校验下载文件，旧同名缓存不能冒充本次交付。升级完成必须读到对应型号、版本和构建时间，仅复制成功不能证明安装成功。
- 编译时间是构建标识，不是设备镜像哈希或可信证明。无法确认时保留 copied_unverified，不自动重试写入。
- 腾讯云优先，GitHub/Gitee 备用；比较远端索引及随包基线，旧镜像不能遮蔽指定的新修订。
- 旧客户端的 latest.json 继续只含 UF2，V2 保持独立 latest-v2.json。
