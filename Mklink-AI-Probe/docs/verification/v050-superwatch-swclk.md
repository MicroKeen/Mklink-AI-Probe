# SuperWatch 的 SWCLK 中断与恢复

2026-11-10，现场在 SuperWatch 已有波形时断开并接回 SWCLK。上位机 0.4.3，MicroLink V4.7.3 编号版，STM32F10x，SWD 30 MHz，采样间隔 1 µs，四个连续的 float。后台仍为 `running`。连续 4 秒观察期间，完整样本数保持在 5,642,204，固件目标读错从 38,733,138 增至 38,958,229，界面数据队列丢弃数为零。状态 5 表示一次目标读失败，不能据此推算漏采点数。

## 上位机

产品提交 `2f605c8c` 在状态接口中增加 `target_read_interrupted`。它来自当前 MUX Watch 订阅实际收到的读错事件。正常静默不触发提示；完整有效样本清除提示。读取中断时采集仍可停止，实测速率显示 0 Hz，恢复后的第一条样本沿用原协议的断点标记。

- MUX、流式采集、记录、复位等 330 项专项通过。吞吐冒烟、数据对齐、DAP 恢复及项目记忆另 68 项通过。GUI 全量 104 个文件、1,204 项通过，生产 Web 构建通过。
- Edge 打开生产仪表盘，连接本分支后台与模拟 MUX 探针。两条有效样本后注入状态 5，界面显示“目标读取中断，等待恢复”和 0 Hz，切换英文后提示仍可见。第三条有效样本使界面恢复运行。整段只有一次 START，期间没有 STOP。

## 联合验收

普通 MicroLink V4 的本地固件候选源码为 `82c70fdf`，构建标识为 V4.7.3 / 2026-11-10 10:22:08，UF2 的 SHA-256 为 `10240cdfc1b0e50055d2a7e44b0ca902b514ab2012cd53441f85411a6f833a0d`。固件故障注入模型中，断线 4 秒产生 20 条状态 5，有效样本数保持不变。原 F103 的 UID 恢复后，同一订阅读到新值；换成另一 UID 时继续等待。其他器件的身份校验取决于可读的 DP、AP 和 ROM 标识。

在同一只普通 V4 和原 STM32F103 上，先测原固件，再刷入上述候选并回读构建标识。两轮均使用本分支后台、相同 AXF、四路 float、30 MHz SWD 和 1 µs 请求周期。测试中只对下载器更新固件，用户在候选稳定采样后手动拔出并接回 SWCLK。

| 实物阶段 | 每秒完整四通道样本组数，5 个一秒窗口的中位数 |
| --- | ---: |
| 原版健康段 | 43,195.2 |
| 候选拔线前 | 43,529.9 |
| 候选接回后 | 43,458.2 |

中断状态持续观测到 12.54 秒，有效样本数一直是 1,994,808。共收到 63 条读错事件。保留同一后台和订阅，下一组有效样本带有明确的中断标记，设备时间由 45,883.096 ms 前进到 58,519.835 ms，缺口为 12.636739 秒。恢复点的四个值约为 64.466、88.814、99.640、95.298。缺口长度包含拔线时间，插回到首样本的电气延迟未单独测量。

候选共接收 2,265,672 组样本，样本序号连续，批次时间单调，只有上述一个断点，二进制队列丢弃为零。恢复后时钟读回 30 MHz。与 RTT 会话并行时，30 次普通读均返回 F103 CPUID `0x411fc231`，Watch 又产出 44,688 组。该时段没有 RTT 日志行，未测得 RTT 字节吞吐。实测范围是本次 F103 工况；H7 高速和 IDE 抢占等其他验收条件仍见[上位机基线](v043-host-baseline.md)。

## V4.7.4 本地升级

同日，固件会话按维护者要求将普通 V4 升至 V4.7.4，保留修复代码并新增版本修复记录。
源码提交为 `dcbdeb36e01262fa7395e2eedebb621ac67db99e`，构建时间为
`2026-11-10T13:55:55`，UF2 Family 为 `0x0A4D5048`，SHA-256 为
`778dd94ccf1bf11fa94b8cd0271fac808cb6444ac41161cc7701e2be53022440`。
本地构建清单状态为 `local_verified`，记录提交为 `98f70cb`；这不代表正式发布。

固件会话记录同一普通 V4 回读版本和构建时间成功，设备 README 与 BIN 一致，
V4.7.3 的五条历史记录逐字节保留，另八个根文件哈希不变。上位机会话核对了
构建清单、UF2 实际哈希及原始采样报告哈希。

升级后在原 STM32F103、四路 float、30 MHz SWD 和 1 µs 请求周期下，健康检查
共收到 223,728 组数据，零读错和二进制队列丢弃，五个一秒窗口速率中位数为
43,486.6 组/秒，时钟回读仍为 30 MHz。本轮没有重做物理拔插，恢复能力沿用
上文相同恢复代码的 V4.7.3 候选实物证据。刷入前已通过正常断开接口释放 GUI
句柄；固件会话报告测试专用后台已退出、探针已释放。
