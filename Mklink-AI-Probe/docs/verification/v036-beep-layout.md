# 蜂鸣时长与预览 / 输出并排

用户要求蜂鸣器可配置毫秒时长，复用既有 `cmd.set_beep_on()`、`time.sleep_ms(ms)`、`cmd.set_beep_off()`；运行输出只在触发测试后出现并与配置预览对齐。

- 普通 V2/V3/V4 脚本直接复用上述三调用，原默认 1000ms 不变；关闭蜂鸣不会生成开关调用。
- UART ISP 的多个板次在单次 `isp_program` 内执行。主机通过既有 `isp_config` 的可选第 13 参数传递时长；不新增蜂鸣能力探测或 Pika 方法。旧配置省略该参数仍生成 12 参数调用；旧固件拒绝新参数时不进入烧写。固件每轮复用既有 PWM 底层，异步关声，不阻塞快速换板。新界面默认保留原实际时长 1500ms。
- 时长整数范围 1–10000ms。禁用蜂鸣后输入框禁用。
- 预览始终保留；点击触发测试后新增运行输出，与预览两列等宽、等高、标题对齐。窄屏改为上下排列。输出继续过滤脚本与原始协议记录。
