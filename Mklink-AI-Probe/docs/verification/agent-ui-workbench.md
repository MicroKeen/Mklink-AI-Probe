实现及 19 组 SuperWatch 功能、A01–A20 映射见 [使用与契约说明](../frontend-workbench.md)。本报告区分自动回归、实际浏览器和未验真机范围；不作为合并、安装或发布资格。

## 实现影响面

- 保留原 SuperWatch、RTT 和串口业务入口，新增“组合工作台”。波形、变量、RTT 通道和串口视图使用独立 ID、显示配置和销毁路径；后台采集、变量选择、录制和设备操作沿用原共享服务。
- GUI/MCP/SDK 共用认证运行时的 `agent-frontend/1` 目录、状态、命令和回执。语义操作绑定页面、项目、实例、探针和 generation；原命令 ID 可查询，未知结果不自动重放。
- 项目布局使用版本、revision、原子写和结构限制。首次旧分组投影只读且待保存；有意保存的空布局不被自动填充。
- 页面用户意图保留对象和可信状态快照，Agent 的答复显示于原请求。请求不是自动设备操作，也不会唤醒已结束的 Agent 会话。

## 实际浏览器与截图复查

使用隔离的真实 MKLink FastAPI 认证后台、临时项目、构建后的 Web 资源和 Playwright 浏览器。后台保持设备未连接，未打开物理串口，未派发硬件写入。截图及运行日志保留在本地忽略目录，不提交到仓库。

- 同屏组合 7 张面板：两组波形、一个变量、两个 RTT 通道、两个独立端口视图；读取完整语义目录和各卡片来源。
- 经真实 broker 派发 `panel.*`、`waveform.*` 和 `layout.*`，查询终态并重复提交完全相同的命令，确认原回执返回且不重复执行。
- 经受控后台文件接口加载 12,000 行约 313 KiB 的 CSV，用原回放 Worker 执行 6 秒 seek、A/B 游标、Y 轴和图例设置；另一张波形保持独立且不进入回放。
- 指定面板导出实际 PNG，浏览器收到约 48 KiB 的图片；这不代表原生保存对话框已验收。
- 实际键盘编辑标题、鼠标拖动、右下角缩放；保存后刷新保留 7 张卡片及尺寸。650 px 窄屏无页面横向溢出，截图可读。
- 恢复布局不启动采集、录制或回放。停止状态请求暂停会明确失败并返回消息，避免报告未生效的暂停成功。
- 旧 revision 保存返回 HTTP 409，当前保存内容不变。最终 7 面板状态报告约 88 KiB，无未捕获的浏览器脚本错误。
- 页面提交意图，真实后台冻结对象及状态上下文，Agent 回复后页面展示；含 HTML 标签的回复作为文本显示。
- 在最后构建的浏览器中让后台保存请求后丢弃 HTTP 响应；页面按原 ID 找回请求并显示回复。实际只 POST 一次、只保存一条记录，没有重新发出相同意图。故障注入产生的预期网络错误与未捕获脚本异常分开核对。

过程中曾修正离线暂停的错误成功状态；一次测试脚本在刷新后误选仍被短暂标为在线的旧页面，后台按预期给出 `unknown`。最终脚本等待新页面注册并绑定该 page ID，没有把旧命令改 ID 重放到新页面。

| 后台与共享运行时 | 上述 9 个 Python 套件，新增共享 manifest、组件保存、v1/v2、停靠、约束与无覆盖错误用例 | 272 项通过；3 条依赖弃用警告 |

| 通用 skill | 模型、starter、scaffold 测试；skill 格式与相对链接检查 | 8 项通过；格式及 16 个链接有效 |

新增 `button`、`form`、`value` 与真实自定义 `indicator` renderer，类型元数据由前后端共用 manifest。组件通过实际 catalog/schema 绑定原业务入口；契约变化拒绝执行。新增、配置、编辑、输入、执行、读取、移动、跨窗口转移、删除与所有窗口/布局操作均有语义入口。单元回归同时覆盖临时草稿不公开、跨窗口保留草稿/unknown、原任务身份与不重放，以及无效变更不产生部分状态。

最终审查修复了配置应用清掉 unknown、恢复不同绑定沿用旧草稿、可选字符串无法显式清空，以及新失败操作显示上一次成功结果的问题；对应回归检查实际 UI 与 Agent 同一路径、恢复原子性和结果身份。

嵌套语义调用改用明确的执行上下文，保留完整目标与 unknown 检查。回归确认 Agent 异步执行期间另一 UI 组件不能绕过并发限制；继承 guard 的调用不会解除外层保护，也不会在结果未知后再次执行业务。

在隔离的真实认证后台和构建后的浏览器中补验：

- Agent 经 broker 新建两个控制窗口、按钮、表单和状态灯；按钮与表单绑定现有 `waveform.legend`，状态灯绑定 `view.legend`。实际鼠标点击与语义调用改变同一份波形状态，状态灯自动读回。
- `component.input` 填写但不执行；表单跨控制窗口转移后保留未提交输入，后续语义执行采用该输入。`panel.dock` 停靠为标签组，实际点击和 `panel.focus` 均可切换。
- 保存包含真实 indicator 类型的 v2 布局，刷新后恢复组件、绑定与停靠；没有自动调用绑定动作，临时表单输入没有写入文件。
- 实际浏览器原生拖动组件标题把按钮移至另一控制窗口；拖动窗口标题形成标签组。切换和停靠保留未提交表单输入。
- 650 px 窄屏无页面横向溢出；动态控制窗口截图可读。最终组合状态报告约 65 KiB，未出现未捕获的浏览器脚本异常。
- 最终生产构建再次加载已保存 v2 布局，完成真实 broker 绑定执行、状态灯读回及语义配置编辑；动态组件的明暗主题截图均已复查，无未捕获脚本异常。

这些操作只使用前端波形显示状态验证绑定；没有以展示动作代替真机业务验收。测试项目、截图和认证状态均留在本地忽略目录。
