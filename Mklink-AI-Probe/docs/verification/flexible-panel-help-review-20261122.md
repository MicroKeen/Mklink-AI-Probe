## 用户入口与真实界面

默认官方 Web GUI 的“帮助”位于“定位面板”旁，普通、编辑和专注模式均可使用。“复制给 Agent”复制当前语言的操作说明、三个自然语言示例，以及公共 Skill 入口、窗口选择、能力发现与回执核对步骤。复制内容与用户工程、布局标题、登录链接无关。剪贴板被拒绝时可直接复制已选中的说明文字。

用 Playwright 操作默认生产资源，以独立工程运行 `_maintainer/testing/flexible_panel_help.playwright.js`。1440×900、320×640、667×375 三组视口涵盖中英文、深浅色。每组均实际读回了剪贴板，核对三个示例和接入指引，滚动到最后一个示例并命中正文。复制按钮保持可见。Esc 返回帮助入口，专注模式和保存状态保持原值。另用禁用两条浏览器复制通道的页面验证手动选择全文。在官方 GUI 新窗口保留可操作的帮助弹窗。

## 图标对齐回归

截图中关闭按钮为 32×32 px，SVG 为 18×18 px。弹窗标题栏原有的 `padding: 0` 被共享表单选择器覆盖，计算样式左右各 12 px；水平中心偏右 6 px，垂直没有偏移。将图标按钮的内边距交由共享规则消费后，实测两个方向误差均为 0 px。帮助、布局库、面板配置、关闭确认四类真实弹窗都检查了图标和点击区域的中心，容差为 0.5 CSS px。另对工程中卡片及控件标题栏的纯图标按钮检查了 320、390、1440 px，每种宽度普通模式 30 个、编辑模式 51 个，均在容差内。帮助按钮和定位选择器也分别在三个宽度实测同排、同高 32 px。
