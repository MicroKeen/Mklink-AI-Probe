# 0.2.2 Web/desktop themes

## Scope

The shared Vue interface now offers System, Light and Dark themes in the header.
The preference is saved locally; system changes apply only in System mode.
SuperWatch and SystemView canvases redraw their backgrounds, axes and text when
the theme changes. Signal colors and active acquisitions are preserved.

RTT and the serial assistant share a transmit bar. Its wrapper now uses the
surface token, removing the white surround reported in dark mode. Forms,
status badges and dialogs also use semantic theme colors. The update history
includes the theme feature. Plugin and Site Agent version metadata are aligned
with the existing 0.2.2 application version.

## Verification in progress

- Chrome: live HPM6E80 three-variable SuperWatch at 30 MHz continues across
  light/dark changes. Preference survives a reload. Canvas background pixels

  transmit wrapper background is RGB(25,29,36), with no white surround.
