# 脱机烧录共享设备工作区与 HPM OTP 型号配置

## 行为

左侧唯一设备上下文包括下载器型号、端口、芯片和下载类型，协议参数随选择更新。右侧镜像页配置算法、固件及烧录选项；OTP/ARM选项字页复用相同上下文。镜像预览与运行日志在下方。UART OTP直接操作与U盘镜像部署有各自明确的操作区域。

HPM类型使用独立OTP界面，ARM继续使用选项字配置。UART页面按系列加载0–127字的分类、字段和模板。尚未读到的值显示破折号，写入只可使用有效快照；切换目标会清理旧快照和令牌。

## 型号与字段依据

依据用户提供的 HPMicro Manufacturing Tool v0.6.0 本地安装包的 configuration/fuseMap，以及官方 SDK 1.13.0 的各系列 hpm_otp_table.h。只保存字段位置、分类、枚举值等互操作所需数据，没有复制工具程序或整份资源。官方介绍：https://doc.hpmicro.com/service-support/technical-articles/216 。本地参考资源SHA256：68d13e14896859fa34c27c10c379e8ff2a7f7d47e391746340593af9b21577bd。

包含HPM5300、6200、6300、6700/6400、6800、6E00、6P00、5E00八组系列。模板根据各系列实际字段生成；例如HPM5300没有EXIP1_KEK字段，不能沿用HPM6700映射。LIFE_CYCLE同时设置低位及高位镜像字段，其他位保留。自定义/CSV允许0–127字；HARD_LOCK等敏感字仍经过同样的快照、预检和明确确认，不在开发验收中实际写入。

## 验证与接口边界

相关179项Python、209项GUI测试通过；TS与Vite生产构建通过。IAB使用生产Web与真实API、隔离模拟CDC验证：共享左侧选择、HPM5301切HPM6200保留UART、对应128字与字段定义、模板Word24预览/确认/模拟写入、页签切换保留草稿并作废确认、ARM选项字及安全/部署设置可见，零控制台错误。模拟资源在关闭后已全部释放。

扩展使用固件profile_v1能力探测、每段最多8字的ROM读取与11参数按字写入接口。已直接用固件生产C模拟生成的read/plan/program JSON交叉校验主机解析。旧固件仅回退HPM5301的69–79用户字，不把未知区域显示为0。ROM拒绝字显示未知；通信失败或跨段身份变化丢弃整份快照。批量执行先全部预检，再数据字、生命周期/限制字、HARD_LOCK；任意写入结果不明立即停止，令牌消费后不重放。CHIP_ID字必须独立配置并重新读取身份。

没有可靠的完整CHIP_ID到型号自动识别表，因此所选型号只决定字段模板，实际CHIP_ID/ROM/SoC绑定到写入预检；它不是板卡唯一序列号。新型号和区域的真机OTP写入尚未验收。开发测试没有修改物理OTP、永久锁或VCC；测试通过不代表量产/发布认证。新的完整区域操作需要对应的下载器扩展固件，旧固件的已验证用户区保持兼容。
