# 客户端与固件更新顺序、Skill 主动提醒

日期：2026-11-13。代码：`55b972ac`，分支 `codex/v0.5.0-fixes`，PR #79。

## 行为

- 桌面检查、下载或等待安装新版时暂缓自动固件弹窗；选择“稍后”后仍可提示固件，
  暂缓不会消耗固件提醒的去重标记。检查失败、离线或平台无更新不永久压住固件提醒。
  原有能力提示保留；手动固件页说明推荐先更新客户端。
- 固件升级期间本窗口的上位机安装按钮禁用。安装前在后台检查连接、采集、在途操作、
  任务和其他运行后台，拒绝忙碌状态，要求用户先完成任务并断开，不自动停止采集。
  空闲后取得 120 秒临时预约，安装期间每 30 秒续约，阻止新设备操作；失败释放，
  遗留预约到期失效。状态读取和心跳继续。其他运行后台须先正常退出。
- 上位机已安装但重启失败时保留“重新启动”，禁止固件升级，不再下载或安装同一更新。
  正常重启后重新连接、重新判断固件。检查云端不会新增探针命令。
- Skill 首次加载发起 `ping(force_update_check=True, background_update_check=True)`；
  单个后台线程检查，立即返回 `checking`，稍后读取结果。同一检查在途不重复启动。
  旧同步参数保持兼容。成功结果缓存 24 小时，失败 15 分钟；首次 force 跳过旧缓存。
  缓存不可写不隐藏已成功取得的新版本。
- Skill 入口和安装参考要求主动用文字提醒 Skill 新版以及授权连接后的固件新版/无法识别
  固件，不只留下工具 JSON。未连接时固件待查，不为版本检查额外连接。两者都更新时先
  更新所用客户端、重载 MCP 与空闲旧后台，再重连检查固件；实际安装仍需用户同意。
- Skill 按 `skill.version` 判断，缺字段时兼容旧索引；桌面版本单列，不把云端桌面版本
  当作本机已安装版本，也不跨固件型号比较。没有新增虚构的最低版本门槛或改动发布索引。
