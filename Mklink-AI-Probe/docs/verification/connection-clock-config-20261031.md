# 连接配置统一时钟入口纠正

2026-10-31，用户明确纠正：时钟应统一使用“配置→连接设备”处的设置，改成下拉，默认10MHz；不应放在仪表盘采集配置。共用`codex/v0.4.2-fixes`，本轮仅修改源码，未重建gui/dist、安装包或Skill，未连接实体探针。

## 最终行为

- 原仪表盘时钟控件移到本地设备连接配置，改名`ConnectionClockControl`；仪表盘不再挂载或轮询这个控件。下拉与串口控件沿用同一字体和对齐。
- 无保存值时显示10MHz，ARM/HPM新连接也显式应用默认10MHz，不继承探针上一连接的残留值。已有保存配置继续保留；默认设置确认失败不降档或重发，仍显示真实警告，不把默认值当作已应用。
- 未连接时选择经`PUT /api/config`保存`swd_clock`，不访问硬件；连接后选择经现有共享debug-speed接口应用并保存同一配置。RTT、RTOS Trace、SuperWatch和普通内存访问继续共享它。端口修改不重发旧时钟，时钟保存中禁止连接/换端口，切换探针前禁止向旧探针发送新时钟。
- 采用缓存能力下拉：支持声明的普通V3显示14档；旧固件/HPM保留4/10/20/30MHz，HPM明确显示JTAG。旧4MHz迁移仍需用户明确选择，不能自动改2MHz。
- 下拉选择后自动保存，失败或已配置但未应用时提供显式重新应用；不自动重放。保留configured/applied区别、设备generation防旧响应、采集中409拒绝且不停止原任务。
