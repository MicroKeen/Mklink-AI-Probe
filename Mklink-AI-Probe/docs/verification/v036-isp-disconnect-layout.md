## 固件排查边界

正常等待路径已有三次间隔查询超时后发送断开，不能只把复位恢复缺口当成此次现场根因。指定固件会话发现 UART RX 缺少显式上拉，目标 TX 拔出后若悬空产生 FRAME/CRC/IO，会清空连续静默计数；重新插入后才产生超时序列。该解释与现象吻合，但未取得现场波形，不能宣称已证明电气根因。

本轮不重放未知烧录任务、不追加 OTP 写入、不改变 VCC。

固件修改 8845cab：只在 HPMLINK ISP 成功占用时保存 RX PAD_CTL、开启上拉与迟滞，释放后完整恢复。复位恢复阶段也在连续三次静默后清除连接并恢复本地 115200；自身复位恢复不会直接授权重烧同一板。FRAME/CRC/IO/ROM 错误仍不能充当换板条件。

指定固件会话的生产 C 时序回归覆盖正常 reconnect 与自身复位：模拟时间 1250 ms 后发布断开，早于重插响应；占用失败、不同引脚基线、重复占用/释放及取消检查通过。36 项兼容性回归、HPMLINK 开/关两种完整 SES 构建、10 个 SWD 时序函数地址及 UF2 载荷/分区检查通过。这些模拟时序结果不代替实际拔插和屏幕验收。
