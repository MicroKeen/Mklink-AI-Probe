# UART / RS485 完整波特率选择验收

日期：2026-11-13。分支：`codex/v0.5.0-fixes`，代码：`ef59cfb7`。

## 修复范围

串口助手的无能力缓存列表原来只到 921600；Modbus 使用手动数字输入，后台上限
4000000。串口 CLI 和远程交换也各有一个 4M 限制，导致 Web 中选择高速值后其他
入口仍可能拒绝。本轮将两个界面共用的选择、相应参数上限和用户 Skill 文档统一。

- V3/V4 普通 UART `uart_baud_profile.h` 定义完整 34 档 300～10000000。
  全部数值见[串口参考](../../references/commands-serial.md)，不只追加整数 MHz。
- 最新普通 V4 RS485 源码共用分频表，并独立声明 `RS485_BAUD_PROFILE=1` /
  `RS485_BAUDS`。上位机按选中接口分别解析 UART 与 RS485 声明，不按版本号推断。
- 有效固件声明优先，只展示它返回的子集；第三方、未查询或声明无效的端口显示
  完整预设并标注支持取决于设备和驱动。已确认旧固件缺声明的显式查询提示升级。
- 刷新列表只读缓存。显式查询复用配对物理探针的共享所有者，查询前后检查身份，
  不自动停止采集或重试忙命令。前端丢弃过期、换端口或卸载后的响应。
- Modbus 改为下拉选择，连接期间禁止改档；已有连接的非预设速率保留只读显示。
- 串口 CLI、远程交换与共享 Modbus 允许到 10M；保留第三方 API 自定义整数速率
  的兼容性，不强迫所有驱动只接受 MKLink 表内数值。

## 真实设备及浏览器

测试前没有活动共享后台。对两只普通 V4 的四个 UART/RS485 接口逐个执行共享
`probe_version` 能力查询，四次均返回 `source=firmware`、34 档、最大 10000000。
未连接 MCU、刷写、复位、更改电源或发送 UART/Modbus 载荷。

实际浏览器加载生产资源，通过以下检查：

- 用户截图中的第三方虚拟串口现在显示全部 34 档，并标为预设。
- 串口助手选普通 V4 UART，点击“读取下载器档位”后显示 UART 固件声明并可选 10M。
- Modbus 选同一 V4 的 RS485，读取其独立声明并可选 10M；切换第三方端口后恢复
  预设标识，不把探针声明转移给其他设备。
- 中英文提示、连接控制和布局可用。选择档位期间串口保持关闭，没有发送请求。
- 浏览器关闭、桌面代理正常退出；本轮创建的后台全部退出，最终无活动共享后台。

现场标识、截图、测试脚本和查询结果保存在本地构建工作根的
`artifacts/v050-uart-baud-20261113`，不提交设备标识或截图到仓库。
