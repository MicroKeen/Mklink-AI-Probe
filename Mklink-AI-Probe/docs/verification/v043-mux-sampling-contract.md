# 0.4.3 当前采样契约与旧在线协议清理

本轮源分支为 `codex/v0.4.3-fixes`。用户已在指定固件会话明确允许清理旧协议，
由后续固件升级承接兼容性变化。此修改不更改产品版本，不构建、安装或发布。

## 在线采样

SuperWatch、VOFA 的内存采集输入、CLI/MCP 有限时长采样统一使用 MUX。
HELLO 必须同时提供位 3、4、9、10，即 `0x618`；缺任一位均在采样 START 和
事件清队列之前失败，提示升级探针固件和上位机，不按版本字符串猜测支持情况。

- `0x32` 保留字采样；单个自然对齐的 1/2 B 区域用 `0x33`，不扩大 MMIO 访问宽度。
- START 必须返回匹配请求周期、非零时基的 8 B 应答。已接受但应答内容不合法时只
  STOP 一次；STOP 失败保留不确定状态并使传输失效，绝不重放 START。
- 保留当前合法的 status 0 单区域事件，以及 5 读取错误、7 调试失效、8 复位恢复超时、
  9 批量事件。批长按实际帧校验，不假设每批有 127 个样本。
- 保留设备真实时间戳、32 位回绕、重置 generation、nonce、epoch、请求 ID、
  物理所有权、调试让出、RTT 独立队列与采样背压规则。
- 移除在线 DMPM 启停、超容量回退、SW01/DMPW 写入及停止回执驱动；
  OLD/B1 与旧写入回执解析仅用于历史离线数据。
- 连续采样最多 15 个物理区域，每个至多 128 B。超容量明确拒绝，不改为轮询伪造连续采样。
- 独立波形窗口发生故障时停止并显示错误，需显式重启；用户修改配置仍可正常重配。
- 当前多区域单帧采样在时限处只完成部分区域时，`incomplete_tail=true`，不返回部分样本。

在线变量写入继续走原 MUX `0x12`，保留目标可写 RAM 范围和 HPM 目标 RAM 交集检查。
仅以写 ACK 判定完成，不自动回读，不因失效或不确定结果切换协议重发。
旧 `DUMP_WRITE` / `DUMP_WRITE_HPM` 文字标志不再决定当前 MUX 写入能力。
普通控制台、串口、RTT、CMSIS-DAP 的既有独立功能不随 DMPM 删除。

## 有限内存导出与 HPM Flash 回读

`read_dump_memory_range_once` / `read_dump_memory_regions_once` 保留 API 名称，
实现改为已有 MUX 内存读：有 bit 6 用 `0x16` 的至多 4096 B CRC 应答，
否则用当前协商量子的 `0x11`。这是在 I/O 前按能力选择，不是失败重试。
有限导出保持至多 512 KiB，HPM ROM 后端保持 32 KiB 上层分段。

每块严格核对地址、长度、CRC、会话与请求身份；最终覆盖完整才返回。
区域之间不合并、不会额外读取 MMIO，也不缓存目标数据。大范围读仍是顺序读取，
不声称原子快照。取消在块边界检查；请求等待受捕获 deadline 与原 3 s 传输上限约束。
响应不确定时传输失效，不重放、不给出部分成功，也不回退 `cmd.read_flash`。

已有采集占用时拒绝有限导出；保留进程捕获锁和共享后台操作租约，不能停止、
排空或替换现有 RTT/SuperWatch。该迁移避免删除 DMPM 后破坏 HPM 烧录回读校验。

## 验证和限制

软件验证通过实际内存中的 MUX 编解码与共享后台路由进行，包含分片、短包、CRC 错误、
错 epoch/请求 ID、busy、缺能力、取消、deadline、STOP 失败、并发捕获、HPM 完整回读，
以及历史离线 OLD/B1 与写入回执解析。原始日志保存在本地
`F:/MKLink-Build/artifacts/v043-mux-only-20261104`，包括失败的中间轮次。
最终集中验证 **37 个测试文件、1234 项通过（52.08 s）**，命令通过
`scripts/build_workspace.ps1 -Action run -BuildRoot F:/MKLink-Build` 执行。
范围包括 MUX、采样宽度/时基、共享路由、RTT、SuperWatch、内存、HPM 回读、
串口能力与停止生命周期；含 10 s / 10 ksample/s 软件流传输检查。
`final-tests.log` 和 `final-results.xml` 是最终结果；含测试链接的运行目录保留，未强删。

本会话没有访问硬件。物理 HPM 烧录后校验、最新宿主与最终候选固件的配套采集、
SuperWatch/RTT/调试并行和安装资格仍需实际验证，不能用模拟协议测试代替。
此前固件测速固定旧宿主源，其成绩不自动归属于本次宿主提交。

最大采样空隙低于 20 µs 仍未达成。空隙显示及固件波形证据见
[视窗空隙验证](v043-sample-gap-visibility.md)。稳定低于 1 ms 的普通内存读取
P95/间隔延迟仍是独立开放项，见 [延迟调查](v043-tail-latency.md)。
