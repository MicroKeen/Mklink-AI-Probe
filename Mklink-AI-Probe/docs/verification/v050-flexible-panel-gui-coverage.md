# 灵活面板：完整 GUI 复用与验证

日期：2026-11-15。对象：v0.5.0 上的本地任务分支 `codex/agent-ui-workbench`，基线 732562e4；不是正式安装包验收。用户要求本轮暂不提交/更新 PR，保留本地修改。

原评审确认的“只接接口、缺完整 GUI”已按全部路由、仪表盘标签及配置分区处理：新增 16 类 `tool`，直接内嵌原 Vue 组件，保留六类原面板，另增日志、信息和分析图表。没有 iframe、新业务后端或任意脚本执行入口。

**完成组件覆盖不等于全部设备场景已通过。** 下表明确区分组件自动回归、真实浏览器、虚拟串口端与真机。未验证的物理能力继续开放原 GUI，但不标为真机通过。

## 人与 Agent 使用同一实现

- 入口 `panel.add(type=tool, tool=...)` 在目录中公开。普通用户从“添加面板”选择完整工具，参数、文件、结果与确认均留在面板内；没有 JSON 编辑器。
- 原控件发现/分派复用 `guiControls`；新鲜 ID、当前值签名、可见性、禁用和目标约束仍生效。所有字段写入按设备操作处理，因为原控件可能立即保存或改频。
- 实例注入作用域隔离原 `useGuiPanel` 注册、DOM/label ID、通道状态和 teleport 弹窗。模态窗口打开时拒绝背景控件；文件/目录沿用原选择器，不接受任意选择器或脚本。
- 事件分派只回 `dispatched`。业务成功、错误、任务进度必须读取原结果/任务；不能自动重试未知操作。
- 真实 UART 运行暴露实时计数使 revision 持续变化的问题，已将实时结果移入显式 `view.read`；配置、绑定、schema 和目标校验保留，已重跑 UART 收发/保存/回放。
- SuperWatch 嵌入实例显式加载/保存 AXF 配置，避免自动覆盖全局配置；布局恢复只恢复显示，不开始采集或发送。
- 日志按窗口/运行实例/目标隔离，最近 200 条，带截断/存储错误说明；信息最多 32 份。内容与布局分开，恢复内容不执行操作。异步问答即使关闭问题框仍进入历史。

## 真机 SystemView 集成及恢复

在用户指定工程的隔离测试副本中接入项目附带的 SEGGER 核心与保留许可的头文件，使用 DWT 96 MHz 时间戳、可嵌套 PRIMASK 临界区、RTT CH2 / 16 KiB 上行缓冲。CH0/CH1 原功能保留。工作阶段 main/motion/ppg/display 用明确名称标记，SysTick 记录 ISR 进入退出；当前项目没有 RTOS，不伪称真实线程调度。

Keil ARMCC 5.06 u6：0 错误、0 警告；Code 22270、RO 1638、RW 104、ZI 41128 字节。现有五组固件主机断言测试通过。首次缺 Global.h 的失败构建及后续修正均保留。

核对目标身份后保存完整 512 KiB Flash，用 MKLink 原生共享任务烧录 APP，独立读回比对。Bootloader 与 APP 扇区外不变。测试后恢复原 APP 所在完整扇区，整个 512 KiB Flash 与备份逐字节一致；原 AXF 已恢复，原页面/亮度控制地址未变。没有芯片全擦、保护、OTP 或电压变化。

真实 UI 显示四个阶段与 SysTick，保存文件含 29729 条事件；初次采样和记录的解析丢弃/目标溢出为 0。持续采集期间客户端流曾发生丢弃和连接变慢，不能称全程无损。检查发现原隐藏 Trace 仍接收/绘制，现已补 active 生命周期：隐藏只停本视图消费者和绘制，显示后重新附着，后台继续。新增回归通过；最终生产构建通过。浏览器控制服务随后不可用，因此**最终 active 修复的长时实页性能复测与最终截图未完成**，保留为下一轮验收项。

JSONL 通过面板真实文件选择器导入，回放状态和任务/ISR 上下文可读取，缩放/时间窗/全览动作已应用；历史回放不启动设备采集。所有源、二进制、失败日志、请求身份和逐字节回读记录留在用户工程 runs 目录，不进入公开仓库。
