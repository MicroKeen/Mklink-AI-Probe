## 行为

- NSIS 使用 `currentUser`，安装器和卸载器的执行级别为 `asInvoker`，默认目录为
  `%LOCALAPPDATA%\Mklink AI Probe`，注册信息写入 HKCU。
- 安装结束不再运行 `--manage-usb-port-names apply`，不修改设备管理器端口名称。
  文件占用检查、旧版本分发元数据清理、用户快捷方式校正和 Web 协议描述保留。
- “修改端口名称”和“恢复名称”使用现有应用内确认框。真实 WebView 检查发现原来的
  `window.confirm` 没有显示确认框，操作随即返回。确认后仍调用原有
  `Start-Process -Verb RunAs` 助手；取消或关闭页面不调用助手。

## 兼容边界与本地证据

现场旧安装目录的既有 ACL 允许普通用户修改，因此可以原地覆盖。本次没有修改
目录 ACL，也没有提权删除旧 HKLM 安装登记或公共快捷方式。旧机器级登记仍保留，
其完整迁移或清理需要另行处理。对于普通用户无权写入的旧 Program Files 目录，
应使用当前用户目录；不能据本机结果声称所有旧机器级安装都能免提权原地更新。

完整依赖树比较另外记录了 832 个历史遗留文件，包括 826 个旧 Web 资源和 6 个
其他包的元数据文件。覆盖安装保留它们，没有将它们当作当前包的新文件。
本机已有 WebView2，本轮未验证缺少 WebView2 的环境。Windows 可执行文件仍未做
发布者签名，未知发布者限制不变。本轮没有实际批准 UAC 或写入端口名称；助手的
提权调用未变，确认后调用助手由组件测试覆盖。
