# 0.4.1 脱机下载器型号自动识别

日期：2026-10-26。代码：`f4f8a180`；沿用 `codex/v0.4.1-fixes` / 草稿 PR #61。

脱机页面原先只获取 U 盘路径，型号一直依赖手动选择。现在状态接口从 USB 身份匹配后的下载器卷读取 `readme.txt` 当前版本，返回 V2/V3/V4 型号与完整版本；不打开 CDC，不绑定下载器或连接目标。

进入或切回脱机页面立即识别，停留页面时每轮完成后间隔三秒刷新；离开页面停止轮询，丢弃旧请求。已识别的型号覆盖旧保存值并显示完整版本；未识别时保留手动配置能力。拔出后清除推断型号，设备身份变动后清除旧预览和部署记录。多设备可以选择具体下载器；没有当前有效绑定或明确选择时不猜选。部署、预览、触发操作期间不更新表单。
