# 0.4.3 Skill/MCP GUI 启动与发现记录回收

2026-11-06，继续 `codex/v0.4.3-fixes`。本轮源码验证，不构建安装包、
不覆盖本地应用或全局 Skill，不合并或发布。沿用已接受的性能基线。

## 问题与修复

客户截图中的 CLI 启动器最多等待 60 秒让页面接入，`--no-browser` 也遵循
该期限；它不是常驻后台入口。原 Skill 没有给 AI 完整的打开、确认页面、
同后台连接和展示流程。另有 CLI `--probe` 选中设备后未执行连接的问题。
截图不能证明客户故障的唯一原因，尤其不能把云端 localhost 当作用户电脑。

- 新增 MCP `gui_open`，使用普通无硬件会话保持后台；打开动作不连接目标或启动采集。
  复用已有后台/窗口，多候选明确选择；工程不匹配拒绝，不能覆盖已有符号或采集。
- 区分等待页面、页面就绪与面板确认。`gui_present` 收到页面确认才返回 displayed。
  同一 MCP 显式 connect 转入同一后台的目标会话；旧实例退出/被替换时拒绝自动另建后台。
- GUI 登录链接单次使用、60 秒过期、最多 8 个待用链接。响应不暴露后台长期令牌；
  重复打开复用待用链接，不反复调用浏览器。过期后显式打开可申请新链接。
  已打开页面和 MCP 会话的寿命不受链接过期期限影响。
- CLI 显式 `--probe` 与原 `--device-port` 一样执行一次连接；保留原 CLI 交接期限。
  Skill 说明更新旧后台的必要条件、同机执行边界和失败后的有限等待。
- 发现流程先检查 PID；新记录带进程创建身份，避免 PID 被复用后误认旧后台存活。
  启动时取得后台/探针 OS 锁，复查原记录及进程后只删除已失效的 `endpoint.json`。
  正常退出仍删除自身发现记录。活跃、未知、含链接或被并发替换的记录保留。
  日志、任务结果、采样文件、临时目录和锁文件不属于本次自动清理范围。

## 实际验证

源码 MCP、Windows PowerShell 7、真实内置浏览器，无硬件连接：

| 项目 | 结果 |
| --- | --- |
| 页面尚未打开，保持 MCP 会话 | 79.10 秒时原后台仍可查询，超过旧启动器 60 秒期限 |
| 获取新链接并打开 | 页面正常登录，地址移除票据，识别唯一窗口 |
| MCP 展示 SuperWatch | 返回 displayed，实际页面为 SuperWatch，未连接设备、0 Hz |
| 重复 gui_open | 返回同一窗口，无第二后台或新登录链接 |
| MCP detach 后 | 原页面仍连接；关闭测试页后后台正常退出 |
| 清理本机历史记录 | 100 份失效发现记录已删除；99 个 PID 已退出，1 个旧 PID 经 CIM/创建时间确认被 conhost 复用 |
| 清理后发现扫描 | 7.67 ms，0 个残留 endpoint / 活跃后台 |
| 最终源码冷启动 gui_open | 1.060 s，返回 awaiting_window；发布进程创建身份 |
| 无页面时 detach 后退出 | 5.220 s，发现记录自动删除，无下载器连接 |

扫描和冷启动是本机单次观测，不是启动时间承诺，也不代表采样吞吐 A/B。
原目录保留的任务/日志没有删除，不能将这次发现记录清理描述为释放大量磁盘空间。

## 检查与边界

最终 GUI/MCP/CLI/Skill 集合 **151 passed**，Skill 格式检查通过。
此前扩展集合运行 347 项，344 通过；三处失败分别为 PID 预检测试替身位置、
UART 作用域新增 GUI 能力的期望值、Skill 入口超过既有字符预算。前两处修正后
相关集合 **244 passed / 1 failed**，剩余文档预算在最终 151 项中通过；
这些集合重叠，不合并为独立测试总数。保留原预算，没有放宽门槛。
扩展检查含发现/进程复用、锁竞争、记录替换/链接、启动/退出、共享会话、UART、
安全边界、代理及既有十秒流性能检查。早期 123 项通过记录也保留。

本轮未改串口接收、MUX 调度、RTT/SuperWatch 数据或调试路径，未刷固件或修改目标。
GUI→目标会话转换有组件测试，实际硬件连接未在本轮复测；V3 正由指定固件会话
进行 UART 工作。此前 V3/V4 四调试器共存与吞吐资格保持，不能把本轮无硬件
验证说成新的设备性能验收。最大间隔 <20 µs、40 µs 零漏采和 P95 <1 ms 仍开放。
