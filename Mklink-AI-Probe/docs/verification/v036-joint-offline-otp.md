# 0.3.6 镜像与 UART OTP 联合脱机任务

## 改动

主机功能源 a3d55b76、bea39ab5、f576a68d，生产 Web bc23b878。脱机页自动识别下载器，不显示 COM 选择；搜索芯片期间保持输入焦点；HPM 隐藏算法面板，在线烧录导航恢复到脱机烧录之前，设备栏和主区对齐。镜像与 OTP 使用同一设备配置及部署按钮，切换页签保留已确认配置。

UART OTP 按官方八系列配置开放全部 Word 0–127，不以 HPM5301、已实测型号或 profile_verified 为入口门槛。包含可编辑 CHIP_ID 的多字任务按普通数据、Word64、Word1/2、Word0 顺序执行；直接批量写入会在 Word64 成功后更新后续身份参数。保留读取状态、当前值一致性、0→1 及硬件保护检查。

联合脚本调用 isp_config、isp_otp_job_config/add、isp_program；部署和触发都检查新接口能力。旧固件缺接口会明确要求升级，不会仅执行镜像而遗漏 OTP。固件先全量预检，镜像成功后才写 OTP，已等于目标值的字跳过写入。任一失败立即停止，不重试未知写入；主机成功判定还要求 otp_verified 等于配置字数。界面显示下载器 LCD 同款 OTP 原因，不打印脚本或 JSON。
