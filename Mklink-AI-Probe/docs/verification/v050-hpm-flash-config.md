# V0.5.0：HPM 四字 NOR Flash 配置

日期：2026-11-13。分支：`codex/v0.5.0-fixes`，基于 `543eea92`。

## 行为

- 在线和脱机 JTAG 页面增加同一 Flash 配置面板，编辑 `header`、`opt0`、`opt1`、`xpi_base_addr`。按器件保存在当前浏览器/桌面客户端，两个页面共用，可恢复参考值和导入/导出 JSON。
- Python 与 GUI 使用同一份 `mklink/hpm_flash_defaults.json` 参考表。器件型号只决定初始参考值，不能证明外接 NOR 与参考板相同；没有默认值的器件允许手动填写，不沿用上一型号的配置。
- 显式 `hpm_flash_cfg` 优先于 `board`，修复同时提供二者时自定义参数被忽略的问题。已知板名也解析为四字参数，在线和脱机默认执行 `hpm.flash_cfg(...)`；未知显式板名保留 `hpm.board(...)` 兼容入口。
- 参数限制为四个 32 位十六进制字符串，兼容 U 后缀；生成的执行命令去掉后缀。配置失败即中止，不继续编程。XPI 控制器基址和 BIN 下载地址独立，原有 USART ISP NOR 配置不变。
- 不完整草稿会恢复为草稿，损坏的保存数据明确提示，不静默改用默认值。操作期间禁用编辑/导入；导入完成前的编辑、换型号、锁定、卸载或隐藏页面会使旧导入失效。修改配置会清除脱机预览和部署绑定，禁止触发旧脚本。
- Skill 文档与共享/独立 MCP 说明同步。CLI 使用 `flash --hpm-flash-cfg`，共享 MCP 使用 `start_job(action="flash").arguments.hpm_flash_cfg`。GUI JSON 的型号及四字参数可复用；本地保存不会自动写入工程配置或同步其他电脑。

## 真实浏览器与 HPM5301

Windows、当前源码共享后台和生产 Web。本轮实时查询为 **HPMLINK / V4.7.4**，目标为用户确认的 HPM5301；JTAG 10 MHz。没有刷写下载器或改变供电。

1. 在线默认四字参数可见。修改后切换脱机页面及刷新，编辑值均恢复。通过文件选择器导入同型号 JSON，在线页面同步显示全部四字参数。
2. 将 header 输入为 `0x100000000`，明确提示 32 位范围并禁用烧录；恢复有效值后可开始。实际烧录使用原参考值，仅更改文本格式验证保存和导入，未猜测另一种 NOR 的参数。
3. 用户 hello_world 工程的 HPM5301 flash_xip Debug BIN，地址 `0x80000400`，52,988 字节。在线任务终态 `succeeded`，PROGRAM / VERIFY 均 100%，临时镜像清理成功。
4. 脱机生成的脚本明确包含 `hpm.flash_cfg(0xfcf90002,0x00000005,0x00001000,0xf3000000)`，不包含 `hpm.board`。独立文件部署成功，触发一次后，设备输出实际 Header/options/XPI 基址、`board download OK`、`auto download finished`。
5. 脱机后经共享内存 API 按 4 KiB 分块独立回读全部 52,988 字节，与原 BIN 完全一致。SHA-256：`d036943cb3aa2832ee2b38f5a0f326efeb0c15848c68dfcc378b323f06684125`。
6. 脱机完成后编辑参数，“触发测试”立即禁用，旧预览/输出失效。正常断开并退出测试后台。两份专用 U 盘测试文件经哈希归档后移除，原有镜像未覆盖。

最后的代码变动仅增加离开页面时丢弃异步导入，随后相关 GUI 213 项和最终生产构建通过；烧录路径未再修改。日志、截图、生成脚本和回读位于本机 `F:/MKLink-Build/artifacts/v050-hpm-flash-config-20261113`。清理共 447 个测试链接及三份临时目录，零失败，F 盘剩余约 19 GiB。

## 限制

- 实物仅验证现有 HPM5301 板的参考 NOR 配置，未更换其他外接 NOR、XPI 控制器或 HPM 型号。自定义参数传递/优先级有软件验证，不能视为所有 Flash 组合实测。
- JSON 导入已做真实浏览器验证；JSON 导出格式及校验通过软件测试，原生保存对话框本轮未单独验收。
- 未执行 OTP 永久写入/锁定、USART ISP 电气下载或新采集性能 A/B。内存读取沿用映射读取，不声称修改 Flash 配置会立即初始化控制器。
- 本轮更新源码、生产 Web 与 Skill/MCP 文档，未生成或覆盖 Windows 安装包。已安装 V0.5.0 仍为 `b3ef9ef4`，本功能尚未进入该安装包。未合并、签名或发布。
