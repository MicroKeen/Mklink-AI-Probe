## 行为

- 仪表盘提供当前探针共用的 RTT/SystemView/SuperWatch/普通内存采集时钟，下拉取后台缓存能力；连接时查询一次能力，轮询状态不访问 USB。
- 仅普通 V3 同时声明版本、完整 `SWD_CLOCKS` 与 `SWD_CLOCK_ACK=1` 时显示 14 档：1/5/10/20/50/100/200/500 kHz，1/2/5/10/20/30 MHz。旧 V3/V2/V4 和 HPM JTAG 保留原四档，不套用新 V3 能力。
- 旧 4 MHz 保持可见并提示显式迁移到 2 MHz，精确应答成功后才保存。新 V3 要求精确 Hz 与唯一 configured/applied 应答；`configured` 表示保存但待应用，不能声称 Keil 时钟变化。`applied` 表示应用时序设置确认，不是频率实测。超时、拒绝或缺少应答不自动重试/回退，不沿用旧成功状态。
- 固件本轮无 `SWD_CLOCK_LIVE`：采集中改频返回 busy，保留所有原任务，不自动停止或重启；待应用时可在退出 Keil、停止采集后显式重设。选择低频时说明可能显著增加并行调试等待。
- 移除配置页手输频率与 SuperWatch 四档选择；配置页保存端口/MCU 不回写过期时钟。MCP 支持 Hz 或兼容 profile 二选一，Skill 引用同步。
- SuperWatch 的专注入口合并到采集工具栏；1920 px 隔离浏览器下同一行高 42 px，900 px 自动换行。专注模式与原控制入口保留。
