# V4＋F103 连接耗时和睡眠访问入口

2026-11-07 使用同一普通 V4.7.3、STM32F103、相同工程和已保存的外设选择，从 Windows 原生桌面点击连接，记录直到界面显示端口的时间。每组首连一次，再断开并重连五次。旧版为已安装的 `2d246431`，更新版为 `33f3c36d` 本地 Windows NSIS 解包后的原生程序。

独立 SDK 分段计时中，旧版首次恢复选定的 SVD 耗时 3081.56 ms，后续三次耗时 462.69–660.20 ms。新版首次准备 SuperWatch 运行时耗时 0.14 ms，后续三次耗时 0.08–0.12 ms。四次真实目标连接耗时 161.5–176.8 ms。外设搜索、添加寄存器或打开外设目录时才解析已保存的 SVD。目标切换仍会清除上一目标的外设条目。解析期间采样线程可继续获取布局锁。

连接页已移除睡眠访问按钮。“配置 → 后台管理”根据当前连接的 SWD 能力显示入口。固件能力声明和目标访问错误都不足以证明芯片正在睡眠。普通连接和采集保持原模式；用户开启睡眠访问时，后台同时校验下载器身份和连接代次。在真实桌面上显式开启后，Memory 读到 F103 的 CPUID `0x411fc231`，关闭模式后正常断开。此前已验证的睡后 RTT 和 SuperWatch 序号完整性见 [F103 睡后数据验收](v043-f103-wake-data.md)。
