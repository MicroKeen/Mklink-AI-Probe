# 0.4.3 普通 V4 IAR 退出恢复与调试共存验收

2026-11-06。接续 [V3 验收](v043-iar-exit-context.md)，上位机产品源仍为
`92ca42e0`，分支 `codex/v0.4.3-fixes`。本轮只增加验收交接，上位机安装及全局
Skill 仍为 `269d826f`；未构建安装包、合并或发布，STM32H743 的 IAR 目标映像未变。

普通 V4 原 E 复现了 IAR 正常退出后持续吞吐不能恢复。最终 r4 消除了这项残留开销，
独立 RTT、SuperWatch 和 4096 B 连续读取对照未见实质退化。四类调试器分别与
RTT/SuperWatch 共存通过，不表示四个调试器能同时争用同一 CMSIS-DAP。

每批释放互斥锁，新 DAP 请求仍优先，执行 DAP 或普通控制访问前恢复上下文。
没有通过无请求超时清 active，也没有声称识别了 IAR 退出。

实际采样时间戳计算。测试未打开 Web 或注入 USB 追踪。
