## 已安装桌面及 HPM6E80

`7b9c7bd2` 的 Windows 安装包从 0.5.0 覆盖升级到 0.5.1。沿用原 D 盘安装目录，安装包内 3,739 个文件与实际安装一致。设置保留，公共桌面只有一个快捷方式。

HPMLink V4.7.5、用户确认的 HPM6E80、SDK 1.12.1 的 `hpm6e00evk` hello_world。JTAG 实测 IDCODE 为 `0x1000563D`，实板 Flash 的 main 开头 64 字节与已知映像一致。控制块 `0x012841D0` 的签名及三个上行、三个下行描述符与 ELF 匹配。原生 Windows 桌面加载该 ELF 并自动搜索，从 CH0 开始采集。

| CLI 观察窗口 | CH0 字节 | 原生桌面、浏览器和 CLI 匹配的文本与波形组数 |
|---|---:|---:|
| 75 秒 | 7,500 | 150 |
| 5 秒 | 500 | 10 |
| 1.25 秒 | 100 | 2 |

三个窗口独立启动，原始字节和独立实时订阅按偏移对齐，丢失为 0。stdio MCP 复用同一会话读回 200 字节，退出后桌面继续收到后续序号。CH1 和 CH2 在本次程序中没有载荷。操作未刷写应用或探针固件。

验收还发现完整 JTAG OTP 读取通过 MCP 调用时返回 422。共享后台的参数校验漏掉只读标志 `extended`。修正后实板经 stdio MCP 返回 Word 0–127 和熔丝、影子、锁定字段。回归覆盖省略标志、布尔真/假、无效类型和更改类调用的拒绝。HPM6E80 永久写入继续暂停，详见[硬件记录](v051-hpm-jtag-otp-write.md)。
