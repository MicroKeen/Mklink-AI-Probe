# 0.4.3 最小 ILM B 对照（2026-11-04）

**ILM B 有局部控制路径收益，但未达到最大采样间隔 20 µs 或 40 µs 零漏采。
本轮不采用候选，原 USB7 已恢复并完成反测。** 上位机产品代码和目标固件均未修改。

## 条件和候选

- 上位机固定 `bd62115d`，产品实现仍为 `0a0c97b3`；本机安装源仍为
  `f9b1ae8a`，没有为本轮重新构建安装包。测试使用固定源码的共享后台和二进制订阅。
- 同一普通 V4/H743，SWD 30 MHz。USB7 build 11:01:27 → ILM B 19:41:56 →
  原 USB7 11:01:27。每阶段 PE2 寄存器/RAM 镜像、40/100 µs 翻转各 3×10 秒，
  请求间隔 4 µs。宽度/最快速度测试固定 40 µs，RTT/DAP 共存固定 100 µs。
- 每阶段先核对物理身份、空闲所有权、构建、目标映像哈希和实际 Flash，再测速度。
  第一阶段原本已为 ARR39；后两阶段在 Flash 校验后显式设置 ARR39，匹配中断负载。
  只按已授权的 40/100 µs 用例修改定时器 ARR 并回读，未改程序、EGR、CNT、供电或 OTP。
- 固件会话只将六个小控制函数及常量放入固定 768 B ILM 段，实际 590 B、余 178 B，
  dispatcher 仍为 XIP。69 项软件回归通过。10 个固定 SWD 汇编内核和接收保护的
  实际初始化字节与 USB7 相同；没有减少缓冲、改变调度或将旧热点移出原区域。
- 链接松弛导致 49 个旧函数入口和 17 项 RAM 对象地址变化；不能称所有 RAM 地址不变。
  三个旧函数合计缩短 32 B，ILM 净增加 558 B；原 DMA/环形缓冲容量和对齐保持。
  候选 UF2 SHA-256：`baf4464be18244bcd3e47419468d68b3d48fd8a7deddca03e1a9730c61d5ca31`。

## 波形与间隔

下表每格依次为该用例三轮的最大采样间隔，单位 µs。

| 用例 | USB7 A | ILM B | USB7 反测 |
| --- | --- | --- | --- |
| PE2 / 40 µs | 47 / 65 / 50 | 47 / 46 / 47 | 48 / 71 / 59 |
| RAM / 40 µs | 64 / 49 / 62 | 57 / 56 / 47 | 64 / 56 / 52 |
| PE2 / 100 µs | 48 / 48 / 49 | 57 / 46 / 47 | 63 / 51 / 48 |
| RAM / 100 µs | 49 / 58 / 47 | 58 / 46 / 49 | 63 / 50 / 61 |

三阶段的采样间隔 P95 均为 PE2 8 µs、RAM 5 µs。普通批间隔中位数始终为
PE2 22 µs、RAM 21 µs，仅这项就仍超过 20 µs。ECHO 回复邻接批间隔有改善：

| 用例 | A 中位数 µs | B 中位数 µs | 反测中位数 µs |
| --- | ---: | ---: | ---: |
| PE2 / 40 µs | 42.5 | 39 | 47 |
| RAM / 40 µs | 47 | 39 | 41 |
| PE2 / 100 µs | 43 | 39 | 45 |
| RAM / 100 µs | 41.5 | 39 | 48 |

40 µs 用例中，超过 1.5 倍翻转间隔的边沿间隔合计：PE2 **542 → 478 → 542**，
RAM **649 → 633 → 656**。仍出现约三个翻转间隔的长边沿，符合未观察到中间翻转的现象。
这些是异常边沿间隔数，不是协议丢包数，也不是精确缺失采样点数。
100 µs 的三个阶段均未观察到该类长边沿；每个用例只测了 30 秒，不外推长稳零漏采。
没有同步逻辑分析仪证明每一个物理边沿，也没有为达到指标改目标程序。

| 共存 DAP P95，ms | 1.057 | 1.136 | 1.006 |

ILM 持续采样增加约 0.17%，RTT 低约 0.2%，波形平均速率变化约 0.05% 以内。
这些变化不足以证明有实用的整体提升。B 的 DAP P95 比两次 A 高约 7.5%/12.9%；
每阶段只有 300 次，不断言固定退化，也不能宣称全部调试性能无退化。
最大间隔仍为 46–58 µs，故不扩大本轮 ILM 方案，保留原 USB7。

## 正确性、失败记录与边界

三阶段共 **69,273,303** 个已发布波形点，完整值及时间戳逐点匹配原始 MUX；
MUX 事件序号空隙均为 0。停止边界未发布的尾部单独记录，不计为运行期丢包。
Watch v2 本身没有 CRC；v1 命令/应答已校验 CRC，不能混称全部帧有 CRC 保护。
另外通过 144 组宽度/对齐/地址案例、66 MiB RTT 全字节校验和 900 次并行 DAP 读；
目标始终运行，三阶段 Flash 223656 B 与映像一致，静态 RAM 图样和定时器配置核验通过。

最初 A/B 各有一次 GPIO 全字常量断言失败，原始数据和失败报告均保留。四条独立
读取路径（CDC GPIO/RAM 镜像、DAP GPIO/RAM 镜像）分别确认 `FF80/FF84` 和
`FF00/FF04`；差异仅 PE7。目标实际 MODER/AFRL 和已链接的 MSP 代码确认
PE7 为 AF12/FMC_D4，不能把该外设总线位当成恒定的 LED 状态。其具体电平变化机制未证明。
最终只接受独立观察过的上述四个完整字，未知值仍拒绝；PE2 必须双态，完整原始字不修改。
A 的既有记录按最终门槛重新离线核验，三阶段全部通过；未改目标引脚配置来适应采集。

候选第一次升级请求因检查脚本解除选择而触发连接状态 HTTP 409，发生于升级处理前，
没有刷写。明确重新绑定同一探针后，使用原受保护入口成功升级；没有清除校验头或修改保护。
恢复按用户已有手动 UF2 授权，原包只复制一次，构建和保护源码核验通过。
pyOCD 在三个阶段均有同类 CoreSight ROM-table 枚举告警；实际 900 次数据读取通过，
不将其隐去，也不外推完整 CoreSight/断点/单步资格。

结束时原 USB7 已通过反测，TIM7 ARR99，所有流停止、探针断开，九个阶段子后台正常退出。
固件用户工作区未套用 ILM 三文件改动；上位机无产品修改、无重新安装、无合并或发布。
