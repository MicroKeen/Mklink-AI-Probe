## 资源取舍

- 73 个厂商 Pack 中的 624 个 SVD 和 596 个 FLM 均有器件描述引用。保留全部成员、相对路径、器件描述、原始来源和许可证。打包阶段按清单取文件，对寄存器描述采用 ZIP LZMA 并重新计算分发档案校验值。
- 内置算法目录覆盖 7,059 个型号，2,224 个唯一 FLM 已按内容去重，每个文件均有算法目录引用。逐一比对算法文件和清单的 SHA-256。
- pyOCD 的 105 个寄存器描述（83 个 SVD 和 22 个 XML）均保留；344 个 Python 模块随应用冻结，移除额外散装源码副本，共 4,072,553 字节。HPM 寄存器资源和许可证逐文件校验一致。

## 验证范围

- 解开两份实际安装包，逐个比对 73 个 Pack 和 pyOCD SVD 库的成员名、顺序、长度和解压字节。另核对构建产物清单、冻结模块列表、算法及 HPM 文件。
- 在空工程、空 Pack 缓存和隔离的用户目录中分别启动两版随包 CLI 和 Web 后台。外设目录 5,031 条记录完全相同。S32K344、S32K312、STM32F407VETx、STM32H743ZITx、HPM6E80 五个型号的在线烧录算法标识与地址范围相同。S32K344 和 STM32F407VETx 的脱机烧录入口返回相同的本地算法和地址。
- 用两个生产读取器解析真实 STM32F407VETx 厂商描述，枚举 11,601 个可读寄存器并核对 GPIOA.IDR 地址 `0x40020010`。
- 打包、Pack、FLM 与外设相关自动化测试 113 项通过，脱机下载回归 115 项通过。此处为无设备回归，随后完成的实板验证见下节。上一验证包的实板记录见[重编译提醒与 S32K344 验收](v052-web-symbol-rebuild.md)。
