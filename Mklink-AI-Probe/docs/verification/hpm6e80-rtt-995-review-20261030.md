因此，日志中的自动关闭发生在读取失败之后；21:06:05.217 的 RTT stop failed 是故障收尾，不能当作用户主动停止的证据。当前复合设备及存储子设备同秒重新到达，支持整机 USB 重新枚举的判断，不能只归因于 RTT 解析。指定会话转述用户确认测试期间没有操作；尚缺固件复位原因及 USB/驱动层现场，不能区分看门狗重启、控制器复位或链路异常。System 日志查询返回无匹配事件，不构成排除这些原因的证据。

WinError 995 表示 I/O 被中止，单独的错误码不指明本次触发者。[Microsoft 错误码说明](https://learn.microsoft.com/en-us/windows/win32/debug/system-error-codes--500-999-)
源码 `_WindowsReadQueue.read()` 从 `GetOverlappedResult` 取得错误；自身正常取消先设置 `_closed`，预期 995 被当作关闭处理。错误传回主进程仅保留字符串，异常链的 errno/winerror 为空，未记录原生取消来源、对应请求或 worker 线程生命周期；当前证据足以定为传输失败，不足以确定驱动/固件根因。[GetOverlappedResult](https://learn.microsoft.com/en-us/windows/win32/api/ioapiset/nf-ioapiset-getoverlappedresult)、[CancelIoEx](https://learn.microsoft.com/en-us/windows/win32/api/ioapiset/nf-ioapiset-cancelioex)

另见 21:10:37.143 的第二次 995。指定会话确认两次均非其主动 stop/disconnect，期间仅被动检查和保存文件；用户此前已确认无操作。快照中首个显式断开发生在 21:12:02，21:12:07 后台退出，两次故障均保留。
`close-receipt.json` 的原始目标控制块解析为 state=3、request=completed=3、accepted=total=10 MiB，说明原目标负载已完成；这不能补回主机未验收的数据。原后台 `device_closed=true`，指定会话继续独立的五个完整 case，不重新烧录或复位，本会话仍不得抢占。

## 后续独立问题：SDK 本地 TCP 连接失败

同晚 continuation 在 `medium / chunk=2048 / iteration=1` 再次中止，保存进度为 3,469,184 / 10,485,760 B、88.314 s。完整链为 `socket.connect` 的 WinError 10048 → `URLError` → `RuntimeErrorResponse`。这是 SDK 访问本地后台时的连接失败，不能并入前两次串口 995 或认为下载器再次掉线。保存的该后台 `connection.jsonl` 只有 started/opening/ready，没有 transport.failed/recovery；后台仍存活由指定会话报告，本会话未在线查询。

脚本紧循环调用 `rtt_read_channel`；当前 urllib opener 复用不等于 TCP 连接复用。高频短连接造成临时端口压力是待验证解释。`tcp-states.json` 仅保存全机汇总（TIME_WAIT 272、Bound 717、Established 100），缺故障采样时间、四元组、PID 及动态端口范围，不能据此确认耗尽。10048 的定义是地址已占用；端口耗尽需要结合连接及系统证据定位。[Winsock 错误码](https://learn.microsoft.com/en-us/windows/win32/winsock/windows-sockets-error-codes-2)、[Microsoft 端口耗尽排查](https://learn.microsoft.com/en-us/troubleshoot/windows-client/networking/tcp-ip-port-exhaustion-troubleshooting)

指定会话计划仅将测试脚本的缓存读取间隔改为 20 ms，不改探针调度或安装；该条件尚待完整轮次验证，不表示 SDK 根因已修复，失败轮次仍保留并排除。本会话只更新边界记录，未修改产品、系统网络设置或访问设备。
原证据为 `reports/continuation.json` 和 `logs/continuation-failure/`；本会话只读快照位于上述 F 盘证据目录的 `continuation-ipc/`。
