# Modbus 工作台断开与端口刷新验证

0.5.2 开发分支源码 `08bddf6f`，生产 Web 资源 `1fbcb794`。Windows Edge 加载生产页面，使用隔离后台、真实 pymodbus RTU 编解码和可控制应答的模拟串口。

| 操作 | 观测 |
| --- | --- |
| 后台以 20 ms 间隔读保持寄存器，从站持续返回 FC03 异常码 02 | 断开前共发出 35 次请求。页面显示一条可关闭的错误，关闭后帧日志继续更新，断开后串口和工作线程释放。 |
| 从站无应答，通信超时 10 s、重试 5 次，发送后单击断开 | 约 29 ms 后端口选择恢复可用。模拟线路仅发出一帧，后台已释放端口占用。 |
| 再次连接，读取一个保持寄存器 | 读回十进制 42。随后循环读取收到异常码 02，循环停止，提示可关闭。 |
| 枚举时新增端口，再移除原选中端口 | 手动刷新可看到新增端口，原选择仍存在时保留，离线端口被移除后选中可用端口。 |

Modbus 相关 Python 测试 304 项、前端相关测试 33 项通过。生产构建通过，交付目录 92 个文件与浏览器验证资源逐个比对 SHA-256 一致。现场 CH340 和安装版桌面程序待实测。
