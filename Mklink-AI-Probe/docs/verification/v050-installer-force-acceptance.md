# V0.5.0 强制覆盖安装与 STM32F103 验收

日期：2026-11-14。产品冻结提交：`14b86cd0bbd520902b61a8d6b659160e5d1c2e6e`。
分支：`codex/v0.5.0-fixes`，PR #79。已在 Windows 普通用户环境覆盖安装，未签名、合并或发布。

## 安装行为

用户最终要求覆盖安装直接强制结束旧进程，替代此前“空闲自动退出、忙时等待”的方案。
安装器直接结束当前用户的 MKLink 桌面、共享后台、独立 Skill/MCP 入口及对应 WebView 子进程；
不依赖旧版提供退出接口，不判断采集/烧录是否空闲，正在进行的任务会结束。
按实际 Python 入口匹配，不因命令行偶然包含 mklink 而结束其他 Python，也不结束 Codex、Claude 或其他用户进程。
结束前核对进程创建时间，避免 PID 复用；重复检查启动竞争。文件仍不可写时保留明确失败提示，不绕过目录权限。

保持 currentUser / asInvoker，不请求管理员权限，不重命名 USB 端口。
损坏历史仍按[前轮报告](v050-usb-hpm-overwrite.md)备份、核验后初始化；有效未知结果保留，不重放旧操作。
应用内自动更新原有互斥检查保持不变；本次强制行为发生在覆盖安装器中。

实际安装前，旧安装版正在 SuperWatch 采集，已读 306733 组。覆盖安装结束 4 个旧原生进程，
同时结束实际 Python Skill 与冻结 MCP 进程，无关 Python 保持存活。
安装约 13.44 秒，退出码 0、完整性等级 RID8192，3683 个安装载荷文件逐个一致。
6 份用户配置、USB 显示名称和旧机器级安装登记保持不变。
新原生窗口正常启动与退出，后台使用冻结 sidecar，无系统 Python 子进程。

- GUI 全量 109 文件、1270 项通过；生产 Vue/TypeScript、PyInstaller、Rust、NSIS 构建通过。
- 安装前后冻结 CLI 和真实 stdio MCP 在仅 Windows 系统 PATH 下通过：版本 0.5.0、58 工具、
  通用工程显式初始化、型号/安全信息、7059 个算法目标、2224 算法 blob、5065 Pack 目标和 4800 SVD 目标。

使用用户指定 STM32F103RC 工程的原 AXF/HEX；仅复制 AXF 到验收目录，原工程文件及原符号旁配置哈希不变。
MicroLink V4 固定为固件会话交回的 V4.7.4 / 2026-11-14 11:33:15，SWD 10 MHz。
本轮未自行刷下载器、改供电或编程 OTP/RDP；HPMLink 未被上位机验收占用。

### 采集中写入对照

同一固件、同一五变量、同一 1 µs 配置，旧/新安装各做单独采集和 RTT 共存。
每轮 10 次 MUX 写入 100..109，原始样本全部出现相同顺序，最后恢复 0。
四轮均无序号断裂、时间倒退、读错、CRC 错或队列丢弃，写入期间保持 running。

## 保留的限制与清理

- 用户确认未接目标 UART/RS485，因此本轮没有物理串口、Modbus、高速收发验收。
  固件会话双下载器 RS485 报告是另一个验收环境，不合并为本轮通过证据。
- Trace 三次短测解析丢字节分别 34/46/32；原生长一点的显示也出现非零 Runtime Drop 和异常 ISR 编号。
  名称和缩放通过不等于事件无损或所有 CPU/时序统计可信，需另查原始流。
- 未完成外部 Keil/GDB 调试器共存、所有断点模式、八 RTT 通道全量字节对照、VOFA 专用数据流、
  长时间压力和既有 20 µs / 40 µs 性能目标；不宣称全功能发布门禁全部通过。
- 未做安全熔丝永久写入、另型号目标或本轮 macOS 验收；HPM 多板循环初始化旧疑点仍待单独排查。
  固件会话的 10 Mbps 大帧 RS485 边界仍保留，不以当前短测掩盖。
- 普通用户无法强杀管理员启动的旧进程或覆盖无写权限目录，遇到这种权限边界仍会明确失败，不自动提权。
- 最终停止采集、断开目标并正常退出窗口和后台。三个测试 U 盘文件校验归档后定点清除。
  本轮清理七个完成的测试目录及 3583 个测试链接；只读夹具核对后清除，最终无失败。
