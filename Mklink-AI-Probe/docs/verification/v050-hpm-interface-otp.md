# V0.5.0：连接前时钟、HPM 器件选择与脱机 OTP

日期：2026-11-13。分支：`codex/v0.5.0-fixes`。基于 `7d9a109e`。

## 修复范围

- 配置页只在**已有连接且选择另一下载器**时禁用时钟控件。断开状态选择具体串口后，可预设接口和时钟；原有多下载器身份、占用及连接代次保护不变。
- 在线和脱机 JTAG 页面移除重复的 HPM 板卡选择，按所选器件使用已有默认 Flash 配置。未映射的器件明确提示并禁用烧录，不沿用上一器件的隐藏板卡配置。CLI / MCP 的显式 `board`、`hpm_flash_cfg` 参数保留。
- 脱机 JTAG OTP 改为与 USART ISP 类似的读写视图、4/8 列 Word 表格、单字编辑、CSV/TXT 导入及 CSV 导出。仅开放 HPM5301 用户 Word 69–79；系统字段另行只读展示。
- 读取绑定所选物理探针和连接代次。换器件、探针、连接代次或断开会清除快照及待确认配置；普通状态轮询不清除编辑。
- 待部署配置必须提供预期旧值，拒绝将已有 1 位改回 0；写保护要求明确 HARD_LOCK。修改后重新确认，未确认草稿阻止部署。沿用后端 `hpm_user_otp` 配方，不提供即时烧写入口。GUI / Skill / MCP 的写入顺序和保护边界一致。

## 真实浏览器与 HPMLink

使用 Windows、当前源码共享后台及生产 `gui/dist`；单只 HPMLink V4，实际查询返回 **HPMLINK / V4.7.3**。用户明确确认目标为 **HPM5301**。无其他 MKLink 后台占用。

1. 指定命令串口后，连接前 SWD/JTAG 和 5/10 MHz 可选择；以 JTAG 10 MHz 连接成功，界面显示已应用。此结论是固件确认，不是 TCK 物理测量。
2. 在线和脱机均选 HPM5301，重复板卡选择不再出现。
3. 新 OTP 页面实际读取 Word 69–79、影子值、锁状态和系统字段。Word 69 为 3，其余用户字为 0，HARD_LOCK 为 `0x30400016`。添加再清除未确认草稿正常，中英文视图显示正常；本轮未确认或部署任何 OTP 配方。
4. 镜像来自用户指定 hello_world 工程的 **hpm5301evklite / flash_xip / debug** 构建。先核对 CMake 缓存及 ELF 加载段，再用对应 BIN；未使用同目录的 HPM6E00 构建。
5. 在线 ROM API 实际烧录并逐字节校验 **52,988 字节**，地址 `0x80000400`，任务终态 `succeeded`，生成的临时镜像正常清理。生产浏览器日志显示 PROGRAM / VERIFY 完整进度。
6. 脱机通过生产浏览器生成预览、部署独立脚本和镜像、触发一次烧录，输出 `board download OK` / `auto download finished`。脚本使用派生的 `hpm5301evklite` 配置，无 OTP 或供电操作。部署文件哈希与源镜像一致。
7. 脱机完成后，经共享内存 API 分 4 KiB 块回读全部 **52,988 字节**，与源 BIN 完全一致。首次整段请求被 4096 字节上限拒绝后按接口限制分块；不是重放写操作。


烧录后重新读取用户 OTP，值、影子值及 HARD_LOCK 与烧录前相同。目标保留 hello_world；无下载器固件升级、供电设置或熔丝写入。正常断开后退出测试后台，独立测试脚本和镜像经哈希校验归档，再从 U 盘移除；原有文件未覆盖。
