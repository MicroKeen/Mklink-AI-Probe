# v0.2.2 RTT boundaries and narrow/unaligned sampling

This is development validation, not a release qualification. The customer ELF and target program were unavailable; the reported low RTT address is not assumed to be RAM on an unidentified target.

## Changes

- RTT and SystemView public entry points use `search_size=0` for an automatic search of up to 1 KiB, clipped to the containing trusted writable RAM range, including the signature overlap. An explicit nonzero window remains strict. Control block headers, channel descriptors and data buffers remain validated before streaming.
- Writable ELF sections supplement an existing symbol catalogue rather than being skipped when the catalogue already contains ranges. Low RAM addresses are supported when identified by trusted metadata; arbitrary low addresses are not unconditionally accepted.
- The V2, V3 and V4 SWD block routines stage words in aligned local storage before copying to/from byte buffers. Aligning a target address does not guarantee that the caller's buffer is aligned after a byte prefix.
- The three firmware readers use one halfword bus access for naturally aligned 16-bit data. Previously two independent byte reads could combine old and new values. Byte requests retain their exact width; no speculative wider MMIO read is introduced. Odd-address packed halfwords and multi-variable snapshots are not guaranteed atomic.
- Earlier V2 work included in this development branch exposes 20/30 MHz offline settings for updated firmware and prevents an echoed RTT request address from being mistaken for a successful start.

## V2 hardware checks

STM32F103RET6, revised V2 firmware, no change to target Flash for this test. Temporary RAM code and core registers were restored; the RT-Thread tick advanced afterwards.

| Profile | Mixed-offset/length frames | Dynamic narrow frames | Result |
| --- | ---: | ---: | --- |
| 10 MHz | 2,232 | 45,872 | Pass |
| 20 MHz | 3,050 | 59,906 | Pass |
| 30 MHz | 3,413 | 66,805 | Pass |

The mixed test checks target offsets 0/1/2/3 and lengths 1/2/3/4/5/7/16/31/513, plus an eleven-region stream, against a known byte pattern. The dynamic test alternates atomic word stores between two complementary patterns and checks four byte lanes and both naturally aligned halfword lanes, requiring both values to be observed on every channel. In total 172,583 dynamic frames contain 1,035,498 checked narrow values. No payload mismatch, firmware error flag, CRC error or dropped frame was observed. Parser preamble bytes are command text and are not counted as stream losses.

An initial minimal tight alternator only produced one observed state and was rejected as an inadequate test. The qualified fixture includes dwell loops so every channel observes both states; this is not evidence of variable update bandwidth.

A real RTT control block with a test-scoped trusted range restricted to its 168-byte header/descriptor extent starts successfully with the implicit clipped window and returns live tick logs. Chrome RTT starts with mode 0 and search size 0, returns HTTP 200, and displays advancing tick/sequence output. MCP stdio dynamic RTT starts/reads/stops at 10/20/30 MHz, and dynamic SystemView start/read/stop also pass. This does not certify lossless SystemView capture.

V2 RBL was generated with the official RT-Thread packaging tool; header/body CRC and exact BIN payload were checked before installation. V2/V3/V4 all compile. The V4 cached project had to be regenerated from its current source project to include existing assembly/JTAG/security sources. Only V2 was upgraded and tested on hardware in this round.

## Software checks

376 affected Python tests pass with the existing local FLM assets configured. RTT/SystemView Vue tests pass (56 tests) and the production GUI build succeeds. These counts overlap earlier development runs and are not a full release suite.

## Limits

The 16-bit tearing and buffer-alignment defects were identified in source and corrected. The customer's specific 8-bit glitch has not been independently reproduced; all four byte lanes passed the dynamic regression. No filtering or waveform smoothing was added to conceal bad samples. The actual customer's RAM map cannot be certified without its MCU/ELF.

A broader unrelated Windows remote-file test suite hits twelve symlink privilege failures (WinError 1314 / a dependent counterfactual). No Windows security settings were changed. An initial offline-security test run lacked the local FLM asset root; it was rerun with the existing assets configured. These are separate from RTT and sampling validation.
